## 学习中问过的问题(Claude 整理)

### nn.Embedding

**Q:W 是什么意思?**
A:`nn.Embedding(8, 5)` 执行完,内存里就多了一张 8 行 5 列的浮点数表,这张表叫 W(weight,权重),代码里是 `emb.weight`。一行 = 一个词的词向量;行号 = 词的 ID(0 起点,同 Java 数组)。8 行来自 `num_embeddings`(词表容量),5 列来自 `embedding_dim`(每个词用几个数表示)。

**Q:W 的形状和 `emb(x)` 输出的形状是一回事吗?**
A:不是,这是最初答错的地方。W 是字典本身,永远 `[8, 5]`;`emb(x)` 是按 x 里的数字去翻字典、把翻到的行**抄一份**拼出来的新张量。抄回来几行由 x 里有几个数决定,每行几列由 `embedding_dim` 定死。口诀:**列数是 Embedding 自带的,行数是你喂进去的。** x 是二维时架子不动、每个格子胀成 D 个数:`[2,4] -> [2,4,5]`。

**Q:W 里的数一开始是什么?训练在改什么?**
A:随机数(正态分布撒进去的噪声),刚造出来时行与行的远近毫无语义。训练唯一做的事就是一点点改这些数,改到语义相近的词的行确实挨在一起。词向量不是算出来的,是磨出来的;W 和 Linear 层的 weight 地位一样,都是模型家当。

**Q:一次 backward 之后哪些行会变?**
A:只有这个 batch 里出现过的 ID 对应的行。没参与前向计算的行对 loss 没贡献,backward 派不出"往哪挪"的条子,step 时原地不动。推论:高频词被磨得多、向量质量好;生僻词几乎还是初始噪声,所以建词表要把低频词扔给 `<unk>`。

**Q:padding_idx 是干嘛的?加起来也是 0 不会改变结果?**
A:句子长短不一,短句要补假词 `<pad>`(ID 0)凑成矩形。Embedding 只认数字,看见 0 照样抄行0——不设 padding_idx 时行0 是随机数且会被训练,pad 的数量就泄漏成假信号。`padding_idx=0` 让行0 造表时全 0、训练永不动。第六块模型把一句话的词向量逐位相加当句向量,pad 行全 0 加进去等于没加——"加起来也是 0 不改变结果"正是设计目的。

**Q:查表和 one-hot 什么关系?一张表凭什么能被训练?**
A:一行 one-hot 乘表 W 的规则 = h 的第 i 个数乘 W 的第 i 行再全部加起来;三个 0 把三行乘没,唯一的 1 把那行原样放行。所以 `one-hot @ W` 与 `W[i]` 数学上完全一样,Embedding 只是省掉了绕路(5 万词表省 49999 次乘 0)。它等价于一个没有 bias 的 Linear 层,Linear 能训练它就能训练——课件 5.1"和其他层权重没有特殊待遇"根子在这。

### 文本分类实战(第六节)

**Q:课件"重要步骤 1/2/3"是什么?整个过程没看懂。**
A:三个步骤是三个代码文件的顺序(模型 net.py / 数据 data.py+utils.py / 训练 train.py)。按数据流走一句话 `"Allardyce wins again"`(标签 2 体育):①切词 `["allardyce","wins","again"]` → ②查词表换 ID `[0,2,3]`(allardyce 低频进不了词表归 `<unk>`=0) → ③和同批句子补 `<pad>` 对齐成矩形 `[0,2,3,1,1]` → ④Embedding 查表每个 ID 变 D 个数 → ⑤5 个向量相加成 1 个句向量 → ⑥Linear 出 4 个类别分数,argmax 取最大 → ⑦CrossEntropy 罚分、backward、step 磨 W 里用到的行 → ⑧换下一批。①②③=数据准备,④⑤⑥=模型 forward 三行,⑦⑧=训练循环(同 CNN 那节)。

**Q:B、L 是什么?**
A:补 pad 后的整数张量 `[B, L]`:B=batch,这批几句话;L=length,每句补齐后几个词。就是第五节那个二维 x(`[[3,1,0,0],[2,5,6,0]]` 是 B=2、L=4)。全链形状:`[32,50]` →Embedding→ `[32,50,128]` →相加→ `[32,128]` →Linear 链→ `[32,4]`。第一个数 32 从头到尾不变:进几句出几句。

**Q:Linear 对形状做什么?为什么要四个 Linear?**
A:`Linear(in, out)` 只改最后一维 in→out,前面维度不动;上一层 out 必须等于下一层 in。四个不是必须:一个 `Linear(128,4)` 就能分类(fastText 就这么干,AG News 能到 90%);堆多层是为了能先算中间结论再算最终结论,前提是层间夹 ReLU(两个 Linear 直接相连等价于一个)。128→64→32→4 是漏斗形设计习惯,无理论依据;对这个任务是过度设计。

**Q:相加不应该是 0.8+0.0+1.2 加成一个数吗?**
A:不是。相加是**竖着加**:5 个词向量按位置逐列相加,位置 0 的五个数加成一个、位置 1 的加成一个……结果仍是 D 个数。每个位置管一种不同信息(正负面/具体抽象/…),竖着加是各类信息各自汇总;横着再加成一个数会把不同信息混掉,且 Linear 要吃 D 个数。Java 两层 for:外层遍历列 j,内层把 5 个词的 `words[i][j]` 累加到 `sentence[j]`。PyTorch `torch.sum(x, dim=1)`:`[B,L,D]` 压掉中间的 L 变 `[B,D]`。

**Q:net.py 里有 padding_idx,你却说 6.2 才 padding?6.2 好像没指明 padding?**
A:两个动作撞了一个词。**补 pad**(6.2 `collate_batch` 的 `pad_sequence(..., padding_value=padding_idx)`)是真把 `<pad>` 的 ID 塞进短句末尾;**padding_idx**(6.1 `nn.Embedding(..., padding_idx=1)`)只是登记"1 号是假词,那行保持全 0 别训练",不塞任何东西。号码在 6.2 `build_vocab` 的 `specials=['<unk>','<pad>']` 里出生(<unk>=0,<pad>=1),`collate_batch` 用 `text_vocab["<pad>"]` 查出来补,train.py 再查一次传给模型——四处用的是同一个 1。所以课件写代码顺序是"先模型后数据",运行顺序却是"先建词表再建模型"。

**Q:build_vocab / collate_batch 两段在干什么?text_padded 是填充好的文本吗?**
A:`build_vocab`:specials 排最前编号 → `map(lambda x: x[0])` 只取 tokens 扔标签 → 数词频、`min_freq=2` 过滤只出现 1 次的词(它那行 W 只被磨 1 次,留着是噪声) → `set_default_index(<unk>)` 让查不到的词得 0 而不是 KeyError。`collate_batch` 是 DataLoader 的回调:逐句查 ID → `torch.long` 张量 → 标签减 1(1~4 变 0~3,CrossEntropy 要从 0 编号) → `pad_sequence(batch_first=True, padding_value=1)` 补到这批最长句的长度摞成 `[B, L]` → `torch.stack` 把标签摞成 `[B]`。`text_padded` 就是补好 pad 的那批句子,但内容是整数 ID 不是文字;L 是"这一批里最长的",每个 batch 不同。`batch_first` 不写会返回 `[L, B]`,sum(dim=1) 就压错方向。

**Q:NewsDataset 这段代码在干什么?(要求逐行讲清)**
A:原料 csv 每行三列"类别号,标题,正文",**没有表头行**。①`pd.read_csv(path, header=None)` 读成 DataFrame(内存里的表格),列名自动为 0/1/2——课件漏了 `header=None`,pandas 默认把第一行当列名吃掉,训练集变 119999 条(实测);②`get_tokenizer("basic_english")` 返回一个函数(小写→标点前后加空格→按空格切),先拿到手循环里反复调;③`for index,row in data.iterrows()` 逐行走表,`row.iloc[0]` 第 0 列类别号、`row.iloc[2]` 第 2 列正文,切词后打包成二元组 `(词列表, 标签)` append 进 `self.examples`;④`__len__`/`__getitem__` 是给 DataLoader 调的魔法方法:先问总数,再随机挑 batch_size 个下标逐个取二元组攒成 list 交给 collate_batch。`dataset[5]` = `(切好的正文词列表, 类别号)`。6.2 三段串起来:csv→表格→examples 列表→build_vocab 扫词列表建词表→DataLoader+collate_batch 出 `[B,L]`→net.py。
