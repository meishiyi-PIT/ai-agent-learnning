## 学习中问过的问题(Claude 整理)

### CNN 基础

**Q:通道(C)是什么?**
A:每个像素位置存几个数 = 叠了几张"透明胶片"。灰度图 C=1,RGB 图 C=3。卷积之后通道含义变了:不再是颜色,而是"第几张模板的打分热力图"。通用理解:每个位置携带的几种信息。

**Q:weight 是不是图片的宽?**
A:不是。weight = 权重(卷积核里可训练的数字);width = 宽度(NCHW 里的 W)。两个英文词长得像,完全不同。

**Q:不知道输入图片,怎么算 weight 形状?**
A:根本不需要图片。`Conv2d(in, out, kernel_size=k)` 三个参数就定死了 weight 形状 `[out, in, k, k]`。**图片尺寸只影响输出宽高,不影响参数**——这正是卷积对全连接的核心优势(参数量与输入尺寸解耦)。口诀:括号三参数定 weight,图片尺寸定输出。

**Q:输出尺寸怎么算?**
A:公式 `H_out = (H + 2P − K)/S + 1`(除不尽向下取整),直觉是"窗口能放几次"。速查:k3+p1 尺寸不变;k3+p0 减 2;k3+s2+p1 减半;MaxPool2d(2) 减半。

**Q:卷积层参数量怎么算?**
A:`C_out × C_in × K × K + C_out`(最后是 bias)。防呆口诀:算完乘法,永远 "+ C_out" 收尾(bias 容易忘)。多层网络逐层算再相加;上一层 out_channels 必须等于下一层 in_channels。

**Q:输出通道数到底看哪个参数?**
A:看第 2 个参数 out_channels(造了几张模板),和输入图有几层无关——输入通道数在卷积内部"逐层打分→求和"时被压掉了。

**Q:感受野叠加怎么算?**
A:从顶层的 1 个点开始,每往下穿一层 K×K 卷积,区间两端各伸 (K−1)/2 格,即宽度 +（K−1)。公式:堆 L 层 3×3 → 感受野 = 1 + 2L。相邻窗口大量重叠,所以是"+2"不是"×3"。

**Q:池化会改变通道数吗?**
A:不会。池化通道独立(每张胶片各自缩小),16 进 16 出,只有宽高减半。通道数只有卷积能改。

**Q:池化"零参数",为什么 MaxPool2d 还能带参数?**
A:零参数指没有**可训练**参数(无 weight/bias)。构造函数里的 kernel_size/stride/padding 是**配置参数**(怎么滑窗),类比 `new HashMap(16, 0.75f)`。注意默认值差异:MaxPool2d 的 stride 默认 = kernel_size(不重叠);Conv2d 的 stride 默认 = 1。

### 训练代码

**Q:batch 变大,参数会变多吗?**
A:不会。weight 形状里没有 N 维,batch 里所有图共用同一套卷积核("一枚图章盖 32 面墙")。N 只影响计算量和显存。

**Q:数据是谁下载的?DataLoader 的 shuffle 是什么?**
A:`datasets.CIFAR10(download=True)` 负责下载(仓库);DataLoader 只负责发货:batch_size 一次递几张,shuffle 是否洗牌。训练集要洗(防止一批全同类、防学到顺序假规律),测试集不洗(只判卷不更新,顺序无影响且可复现)。

**Q:`torch.inference_mode()` 是什么?**
A:推理模式——块内不记梯度账本,省内存加速(测试不 backward,账本没用)。测试固定两件套:`model.eval()` + `with torch.inference_mode():`。`with` ≈ Java 的 try-with-resources。

**Q:为什么模型末尾不放 Softmax?**
A:`CrossEntropyLoss` 内部自带 softmax。模型里再放一个 = 双重 softmax,押注被压平(0.66 → 0.45),梯度被削弱、训练变慢。铁律:forward 返回 logits;只有推理时想展示"概率"才手动 softmax。课件 SimpleCNN 带 Softmax 是错误示范,LeNet5 是对的。

**Q:测试时 argmax 直接用在 logits 上,不用先 softmax?**
A:对。softmax 不改变大小顺序,分最高的格子换算后筹码还是最多,所以只判类别可跳过 softmax。

### 网络设计的 why

**Q:为什么是 Conv→ReLU→Pool 顺序?**
A:打分(卷积)→ 清负分(ReLU:没探测到就是 0)→ 摘要(池化在干净分数上取最大)。三道工序顺序有逻辑。

**Q:为什么通道越来越多、宽高越来越小?**
A:通道多 = 越深要认的模式越具体越高级(边→部件→物体),种类爆炸需要更多模板;宽高小 = 故意扔掉精确位置换计算量和感受野。整体是一场交易:用"在哪儿"换"是什么"。

**Q:为什么结尾用全连接?开头不是说拍平是死穴吗?**
A:开头拍平的是原始像素(空间信息未用先毁);结尾拍平的是提炼完的特征(空间信息已用完),此时恰恰需要全连接"汇总全部证据投票"。卷积负责看,全连接负责判。

**Q:`Linear(128*4*4, 10)` 的数字哪来的?**
A:被前面每层"挤"出来的:逐层推形状到最后一张特征图 `[128, 4, 4]`,拍平 = 通道×高×宽 = 2048。改了前面任何一层,这里要跟着改,否则 shape mismatch。

### 交叉熵(三站)

**Q:交叉熵到底在算什么?**
A:罚分表。模型输出 = 把 100 个筹码按把握押在各类别上;裁判只看**正确答案那格押了多少**,按 −log(p) 罚分:押 1.0 罚 0,押 0.5 罚 0.69,押 0.1 罚 2.3,越少罚越狠且加速变狠。一批样本罚分求平均 = loss。公式里的双重求和会"坍缩":y 是 one-hot,乘 0 项全消失,只剩 −log(正确格概率)。

**Q:labels 为什么是整数不是 one-hot?**
A:裁判只看一格,给下标就够了。PyTorch 类别从 0 编号(同 Java 数组)。

**Q:softmax 是干嘛的?**
A:把任意原始分数(logits)换算成合法押注:每个分数过 e^x(全变正数、放大领先优势),再按占比分蛋糕(总和为 1)。分数全相同 → 平摊 [1/3,1/3,1/3]。CrossEntropyLoss = softmax + 罚分表打包,所以模型只交 logits。

**Q:罚分为什么用 −log 不用 1−p?**
A:1−p 封顶 1 分,在"错得离谱"区域坡度趋近 0,模型犯大错感受不到额外压力;−log 越离谱越陡,修正推力越猛,把训练力气自动分配到错得最狠的地方。

**Q:为什么 CIFAR-10 第一轮 loss ≈ 2.3?**
A:刚初始化的模型乱押,10 个格子平摊,每格 0.1 → −log(0.1) = 2.30。这是"纯瞎猜"的数学签名,loss 从 2.3 往下掉 = 开始学会押注。

### 训练三病三药(《2.卷积神经网络深度解析》)

**Q:过拟合/欠拟合怎么分?**
A:欠拟合 = 训练测试都差(没学会);过拟合 = 训练好测试差(背答案)。过拟合本质:模型容量 > 数据信息量(LeNet5 参数 6.2 万 vs CIFAR-10 样本 5 万)。识别:训练 loss 降、测试 loss 回升的"剪刀口"。

**Q:Dropout 为什么能防过拟合?**
A:训练时每次迭代随机把该层 p 比例神经元输出置 0(每次换一批)。背答案靠神经元"合谋",合谋对象随时请假,谁都只能学独立可靠的真本事。只加在 fc 层(参数大户,占 95%),输出层 fc3 不加。测试时 `model.eval()` 让全员到岗——考试当天不吃药。

**Q:梯度是什么?梯度消失/爆炸怎么回事?**
A:梯度 = 每个参数收到的"调整指令"(方向+力度),backward 从出口逐层往回传,每过一层乘该层"传导系数"→ 深网络 = 长连乘。系数<1:0.5²⁰≈百万分之一,浅层聋了 = 消失(症状:深网络连训练误差都降不动);系数>1:2⁵⁰ 上天,loss 变 NaN = 爆炸。同一病根:连乘对"偏离 1"的指数放大。

**Q:残差连接为什么能治梯度消失?+1 不会让梯度失控吗?**
A:输出 = F(x) + x。"+x"支路(恒等映射/传送带)传导系数恒为 1,每层总系数 = 车间系数 + 1。消失场景里车间系数很小(0.05→总系数 1.05),乘 1.05 ≈ 原样传递——传送带是保鲜盒不是扩音器,防归零不求放大。车间全学废时系数 = 1,指令无损直达;正向上输出 = x 原样通过,加层至少不变差。车间系数本来就大属于爆炸病,归 BN 管(残差网络实际都配 BN 用)。记:消失→修路(残差),爆炸→限速(BN)。

**Q:ResBlock 为什么必须 Conv2d(c, c, 3, padding=1)?为什么放在两个改通道的层中间?**
A:y + x 逐元素相加要求形状完全一致 → 块内不改通道不改尺寸。因此残差块是"不改规格的加工站":改通道/缩尺寸交给普通卷积(进出口各一个),64 通道地带内 ResBlock(64) 想串几个串几个(出口天然是下一个的合法入口)——ResNet 堆深全靠这个。粒度:残差连接是**层级**的跳线(整个张量打包走传送带),不是神经元之间的细电线。

**Q:1×1 卷积是干嘛的?**
A:窗口 1 格,宽高不变,只在每个像素位置上把 C_in 个通道加权混合成 C_out 个——纯"通道调整阀",深网络里最便宜的改通道手段。

**Q:BN(批归一化)是干嘛的?**
A:层间"队形整理员":把这一批的中间结果拉回均值 0、散开程度 1 附近([2,4,6,8]→[-1.34,-0.45,0.45,1.34]),每层出口重整队形 → 数值滚不大 → 治爆炸。每通道一套(BatchNorm2d(6) 咬住上层 out_channels),带两个可学习旋钮。

**Q:BN 版代码的三个坑?**
A:①conv 后用 BatchNorm2d(四维),fc 后用 BatchNorm1d(二维),用混报错;②BN 前的层要 bias=False(减均值会抵消 bias),fc3 无 BN 所以保留 bias;③训练模式下 batch 必须 ≥2(一批一个数没"队形"可言),课件测试代码悄悄从 1 张改成 10 张就是这个原因。

**Q:model.eval() 到底管什么?**
A:管"层的行为",两个住户:Dropout(考试不丢人)+ BN(考试改用训练期攒的全局统计)。它不管梯度——梯度账本归 `torch.inference_mode()` 管(忘写只是费内存变慢,结果不变;而忘写 eval() 结果会错且不可复现)。账本开着 ≠ 训练:没有 backward+step 参数一动不动。
