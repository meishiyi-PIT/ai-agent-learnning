## 学习中问过的问题(Claude 整理)

**Q1(第一章 1.3):LoRA 训练的参数很少,是不是除了梯度和优化器状态,也省了权重?权重就是参数吧?**
A:权重 = 参数,没错。但 LoRA 减的是"可训练参数",不是"参数":基座权重一个不删、全部冻结、整份留在显存里,旁边再加小矩阵 A、B。所以权重账不省反而多一点点;省的是梯度和优化器状态只给 A、B 开。7B bf16 对比:全量 = 权重 14GB + 梯度 14GB + 优化器 56GB;LoRA = 权重 14GB + 不到 1GB 零头。adapter 文件小(几十 MB)是磁盘存储的账,不是训练显存。权重账只有量化能省 → 这就是 QLoRA 存在的理由,也是 1.3 说"LoRA 解决的是微调的显存问题,底座本身还得完整加载"的意思。

**Q2(第二章 2.2):流水线并行为什么要传激活值?**
A:激活值 = 一层的输出 = 下一层的输入(四笔账第④笔)。第 16 层在 GPU 0、第 17 层在 GPU 1,第 17 层的输入躺在 GPU 0 的显存里,GPU 1 摸不到,必须拷过去,像流水线的半成品搬到下一工位。反向传播反着来:GPU 1 把"损失对那份激活值的梯度"传回 GPU 0,前 16 层才能算自己的梯度。所以 PP 的通信只在切分点:前向传激活值、反向传它的梯度,各一次 → 通信量最小。

**Q3(第二章 2.3):TP 为什么每一层都要拼结果?**
A:因为每张卡算出的只是半个输出。口算例:X=[1,2],W 左列 [1,2]、右列 [3,4];GPU 0 算 1×1+2×2=5,GPU 1 算 1×3+2×4=11,完整输出 [5,11] 各卡只有一半。下一层的矩阵(也切开)每一列都要乘完整的 [5,11],所以进下一层前两卡必须交换、凑齐 → 这就是"拼",每层输出都残缺就每层都拼。对比 PP:GPU 0 拿的是完整的层,输出完整,只在段边界传一次。补充(课件没提):Megatron 用"列切接行切"省掉一半的拼,一个 Transformer 层前向实际 2 次通信,但仍逐层发生。
