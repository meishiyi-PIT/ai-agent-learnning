1. 我把第三章八步、三坑、DDP 四条全写进去后，用户说"不需要什么都记录进去，你需要记录重点，以及我反复追问你的问题"。

3. 2026-09-29 我把量化实战一节写成两空格缩进的纯文本（"  追问：xxx" + 段落），用户说"以后写进去的还是要注意一下格式 比如问题加粗 几级标题 方便人类阅读"。
   → 用 Markdown 层级写：章 `## `，章内 `### 故事线一句话` / `### 🔖 本章要记` / `### 追问 Q&A（日期）` / `### 勘误`；每个问题一行 `**Q：……**`，答案紧跟其后不缩进；多步过程用有序列表，勘误用 `- **要点：** 说明`。不再用缩进模拟层级。

5. 2026-09-29 开学课件 6《大模型架构与训练全流程》时用户再次确认：本篇追问照旧全部追加进该文件、"跟之前学习的习惯一样，注意格式"。文件末尾有几行用户随手记（"ai整理，画一个流程图…"），新章节插在最后一个正式章节之后、这些随手记之前，不要覆盖或挪动它们。

**Why:** 这是用户复习用的浓缩笔记，密度过高等于没法复习（同 [[pacing-small-chunks]]）；追问过的问题才是用户真正的薄弱点；缩进纯文本在编辑器里没有层级、扫一眼找不到问题，加粗和小标题是给人扫读用的。
**How to apply:** 学完一章就按上面三样追加一段（用 Edit 接在该章末尾，别动前面章节和用户自己随手记的行）；用户追问某点时，答完顺手把"**Q：** + 答案"补进该章的 Q&A 小节；写之前先看一眼文件里相邻章节的格式保持一致。
