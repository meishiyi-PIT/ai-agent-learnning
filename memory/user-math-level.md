用户自述对神经网络/AI 底层算法里的数学概念不熟悉：导数、偏导数、梯度、链式法则、矩阵乘法、正态分布(μ/σ)、log/交叉熵、Σ 求和记号等都需要从零补。2026-08-22 学模块五(神经网络)时明确提出。

**Why:** 用户是 Java 工程师出身，微积分/线代/概率没有可用底子，不先补数学直接读底层算法课件会卡死。
**How to apply:** 讲模块五及任何 ML 底层内容时，先把该块用到的数学按 [[teaching-concepts-first]] 两段式补齐(纯定义+直觉+可手算算例，讲完统一映射到课件/代码位置)；用程序员类比(Σ=for 循环、导数=改一点看变多少、求导规则=查表调 API)；希腊字母/记号首次出现必须解释读法含义。与 [[user-python-level]] 同策略：掌握后只讲难点，不重复讲已会的。
