2026-09-22 学模块六 LoRA 第 2 站时，我按"每小块一道确认题"推进，连问三轮后用户说"继续吧 别问了"。

**Why:** 用户理解顺畅时，连续小题会打断节奏、变成拖慢进度的仪式；用户要的是往前走，检验放在更大的粒度上。

**How to apply:** 每个小块（2a/2b/2c 这种）结尾**不出题**，只给"答案对照"（把本块该会的结论一句话列出）；确认题降到**每站收尾一道**（或用户主动说"考我"时）。用户答错时照常纠正并记入 Q&A。这是对 [[tutor-role]] 第 13/14 条和 [[pacing-small-chunks]] 的粒度修正，不改变"跑 demo 对照输出"这一环。

**第二次纠正（2026-09-28 模块六量化课件 A-1 时）：** 我留了一道"把 token 砍到 500 亿算天数"的手算题等用户报数，用户说"不能用算了，你每次直接把答案也直接给我就行，直接开始第二小节吧"。即：**不再布置手算题等用户回答**——数字题直接把答案和一句解释一起给；每步结尾唯一的"👉 你做"只能是**跑 demo 看输出**（动手，不动笔算）；每站收尾那一道确认题也改成"给答案对照"式（用户主动说"考我"才出题）。原因同 [[pacing-small-chunks]] 第三次纠正：内容不熟时，手算是额外负担，专注力要留给理解。

**第四次补充（2026-09-28 量化课件 4.6 显存账时）：** 我连续三轮拆"7B 全参/LoRA/QLoRA 显存怎么算"（16 字节账、A/B 参数量、线性层与 Embedding 分堆），用户说"说实话我有点没太看懂计算的过程"，再问"不计算这个行不行"。→ **数值推导类内容（显存账、参数量、FLOPs）默认只给定性结论 + 一句为什么，不展开逐项算**；用户主动要"讲讲公式"时才拆，且拆一轮不懂就立即收回到结论，不做第二轮、第三轮更细的拆解（三轮拆符号是错误信号，见 [[teaching-concepts-first]]）。工程上用 gpu_poor 计算器或 nvidia-smi 实测替代手算。

**第五次补充（2026-09-28 模块六《4.微调数据集指南》1.1 时）：** 我留了"你的 train.json 17,660 条属于哪一档"让用户答，用户说"不在现在做训练，统一在这篇文档结束后进行代码的处理，如果遇到小的问题你直接给我把答案给我"。→ 概念类课件全程**只读对话**：每步结尾不留任何待答问题（小问题直接自问自答给答案），"👉 你做"退化为"读课件第 X~Y 行，没疑问回'下一节'"；所有代码走读/跑 demo/动手**攒到整份课件讲完后统一做**（与 [[pacing-small-chunks]] "攒到租卡/动手日一次跑完"同一条线）。

**第三次补充（2026-09-28 模块六分布式训练开学前）：** 用户说"你可以问问题 但是同时需要给出答案"。即：**提问不禁止，但每个问题必须和答案一起给**——用"问题→答案→一句为什么"的自问自答格式引导思考，不留白等用户作答；用户主动说"考我"时才留白。
