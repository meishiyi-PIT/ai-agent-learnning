智服中台课程

1. 将整个压缩包解压到一个文件夹。
2. 双击该文件夹中的 index.html，使用 Edge 或 Chrome 阅读。
3. 保留文件夹中的全部文件与目录；复制课件时请复制整个文件夹。

课程正文、图解、参考答案、源码搜索和十个代码阶段均可以离线查看。
阅读课件无需安装 Node.js、Python、Docker，无需启动网页服务。
课程目录中的“完整源码”可以下载最终教学阶段源码和十个阶段的 Git 历史。
执行文章中的开发实验时，按照“代码阶段与环境操作”准备实验环境。

入口：index.html
源码阅读：source.html
最终阶段源码：downloads/zhifu-course-source.zip
全部教学分支：downloads/zhifu-course.bundle
Git 历史下载包：downloads/zhifu-course-history.zip
