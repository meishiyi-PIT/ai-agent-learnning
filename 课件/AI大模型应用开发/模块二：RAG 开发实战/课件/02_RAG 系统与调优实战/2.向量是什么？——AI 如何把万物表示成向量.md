### **<font style="color:rgb(0, 0, 0);">1：什么是向量</font>**
<font style="color:rgb(0, 0, 0);">文字、图片、声音，这些东西本来不是数字，怎么让计算机处理它们呢？</font>

:::info
_**<font style="color:rgb(15, 76, 129);background-color:rgb(247, 247, 247);">向量，就是一串数字。</font>**_

<font style="color:rgb(63, 63, 63);">把一个词、一句话、一张图，转换成一串数字（比如 </font>`<font style="color:rgb(221, 17, 68);background-color:rgba(27, 31, 35, 0.05);">[0.12, -0.45, 0.88, 0.03, ...]</font>`<font style="color:rgb(63, 63, 63);">）</font>

:::

<font style="color:rgb(0, 0, 0);">我们从一个生活中的例子开始。</font>

<font style="color:rgb(0, 0, 0);">可能会列几个维度，然后给每个维度打一个分</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1781597886570-047dab94-5a0f-4f12-a02c-cb47f0313a43.png)



<font style="color:rgb(0, 0, 0);">几个数字，就是几维向量。</font>**<font style="color:rgb(0, 0, 0);">按固定顺序排列的一组数字，用来表示一个对象。</font>**<font style="color:rgb(0, 0, 0);">一个数字只能表示一个维度。一串数字，才能表示一个复杂对象。</font>

:::info
**<font style="color:rgb(0, 0, 0);">向量 = 一串有顺序的数字，每个位置表示一个维度上的取值。</font>**

**<font style="color:rgb(0, 0, 0);">按固定顺序排列的一组数字，用来表示一个对象。</font>**

**<font style="color:rgb(0, 0, 0);">向量其实就是用一组数字，从多个维度表示一个对象。万事万物皆可向量化。</font>**

:::

### **<font style="color:rgb(0, 0, 0);">2：为什么万物都可以表示成向量</font>**
:::info
那如果对象更复杂，怎么办？

很简单：加维度。

一张图片，可以把每个像素点的取值，按照一定顺序排列成向量。

事实上，很多图像识别算法就是这么处理图像的。

一段声音，也可以把每一瞬间的振幅、频率这些信息，按照一定顺序排列成向量。

一个学生，可以用成绩、兴趣、作息、性格这些维度表示。

一个词语，也可以用很多维度表示：常和哪些词一起出现、偏正面还是负面、更接近“猫”还是“汽车”。

所以，任何事物都可以用向量来表示。

把一个事物对应到一条向量上，这个动作可以叫映射，可以叫向量化，也可以叫 embedding。

:::

<font style="color:rgb(0, 0, 0);">任意事物都可以表示成向量</font>

**<font style="color:rgb(64, 184, 250);">大模型不是直接读文字，而是先把一切变成数字</font>**

:::info
<font style="color:rgb(15, 17, 21);">“今天天气真好！”——这话你一听就懂，但AI模型听了完全懵，它根本不知道“今天”“天气”“真好”是啥意思。</font>

<font style="color:rgb(15, 17, 21);">对AI模型来说，不管是文字、图片，还是声音，想让它处理，</font>**<font style="color:rgb(15, 17, 21);">第一步都得变成它唯一认识的东西：数字</font>**<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">怎么变呢？比如：</font>

+ <font style="color:rgb(15, 17, 21);">“今天” 变成一串数字：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[0.12, -0.35, 0.88, ...]</font>`
+ <font style="color:rgb(15, 17, 21);">“天气” 变成一串数字：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[0.18, -0.31, 0.82, ...]</font>`
+ <font style="color:rgb(15, 17, 21);">“真好” 变成一串数字：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[-0.71, 0.44, 0.09, ...]</font>`

<font style="color:rgb(15, 17, 21);">所以，模型看到的根本就不是“今天天气真好”这几个字，而是一大堆</font>**<font style="color:rgb(15, 17, 21);">密密麻麻的数字列表</font>**<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">这串数字，在技术里就叫</font>**<font style="color:rgb(15, 17, 21);">向量</font>**<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(221, 221, 221);background-color:rgb(39, 40, 34);">向量:一切数据进入模型后的基本单位</font>

<font style="color:rgb(221, 221, 221);background-color:rgb(39, 40, 34);">在AI大模型中我们使用的向量是高维向量(维度越高，包含的信息就越多，</font><font style="color:rgb(43, 43, 43);">能表达的细节通常也越丰富</font><font style="color:rgb(221, 221, 221);background-color:rgb(39, 40, 34);">)</font>

:::

### **<font style="color:rgb(0, 0, 0);">3：向量运算代表什么含义(余弦相似度)</font>**
<font style="color:rgb(15, 17, 21);">词语都不是孤零零的，词语和词语之间是存在语义关系的(近义词，反义词)，在AI大模型中如何表示词语之间的语义关系？</font>

<font style="color:rgb(34, 34, 34);">通过计算向量之间的距离（余弦相似度），模型就能判断词语的语义相关性。</font>

**<font style="color:rgb(34, 34, 34);">把每个词对应的向量在坐标系中画出来，语义相近的词在坐标系中的距离也相近。</font>**<font style="color:rgb(34, 34, 34);"> 这就像给每个词分配一个"语义坐标"。</font>

<font style="color:rgb(34, 34, 34);">"苹果"和"葡萄"等水果类词在向量空间中聚成一团</font>

<font style="color:rgb(34, 34, 34);">我们在</font><font style="color:rgb(43, 43, 43);">很多维度上描述一个词[大小，甜味，价格]</font>

<font style="color:rgb(89, 89, 89);background-color:rgba(64, 184, 250, 0.1);">向量用很多维度一起描述一个词语，含义相近，对应的距离也接近。</font>

:::info
使用向量之间的夹角距离来表示词语之间的语义关系

:::

:::info
<font style="color:rgba(0, 0, 0, 0.9);">点积可以粗略理解为：两个向量在同一方向上有多少“重合”。不过要注意，点积不只受方向影响，也会受模长影响。所以余弦相似度后面还要再除以两个向量的模长。</font>

<font style="color:rgba(0, 0, 0, 0.9);">余弦相似度想比较的是</font>**<font style="color:rgba(0, 0, 0, 0.9);">方向</font>**<font style="color:rgba(0, 0, 0, 0.9);">，不是单纯比较数字大小。</font>

<font style="color:rgba(0, 0, 0, 0.9);">B 的模长明显比 A 大很多，但它们方向一样。所以公式里要除以两个向量的模长，把“模长差异”的影响抵消掉，最后重点看方向是否一致。</font>

:::

<font style="color:rgb(15, 17, 21);">余弦相似度是一种通过计算两个向量夹角的余弦值来衡量它们相似程度的度量方法，其数值范围在-1到1之间，其中1表示方向完全相同（高度相似），0表示正交（无相关性），-1则代表方向完全相反；它关注的是向量的方向而非长度或大小，因此对数据的绝对数值不敏感，特别适用于比较文本的相似性计算，其核心计算公式为两个向量的点积除以它们模长的乘积，本质上是在对向量进行归一化后的内积运算。</font>

:::info
总结:

+ <font style="color:rgb(1, 1, 1);">一个数字只能表示一个维度，一串数字才能表示复杂对象</font>
+ <font style="color:rgb(1, 1, 1);">向量就是一串有顺序的数字，用来从多个维度表示一个对象</font>
+ <font style="color:rgb(1, 1, 1);">万事万物皆可向量化</font>
+ <font style="color:rgb(1, 1, 1);">一旦对象表示成向量，通过余弦相似度来计算相关性</font>
+ <font style="color:rgb(1, 1, 1);">AI 处理文字、图片、声音的第一步，就是把它们表示成向量</font>

:::

:::info
**<font style="color:rgb(15, 76, 129);">向量是语义的数字化表达。</font>**

<font style="color:rgb(43, 43, 43);">在AI大模型中我们用一种统一的方式来表示数据</font>

:::
