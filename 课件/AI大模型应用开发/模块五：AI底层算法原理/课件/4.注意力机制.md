### 1.2 把这套思路搬进神经网络
深度学习里的注意力机制，干的就是同一件事，只不过"眼力见"换成了"权重"：

> **输入里每个位置都分到一个权重，重要的拿大头，无关的拿零头，模型按这个分配方案去整合信息。**
>

给谁注意力多，给谁注意力少，和模型的参数有关系，是模型训练的结果，不断调整模型的参数，模型的注意力， 是模型学习到的结果。

注意力是一场**资源分配游戏**：预算是固定的，怎么花最划算，就是模型要学的核心本领。

在深度学习中，注意力机制的核心作用是让模型**学会聚焦关键信息，忽略无关信息**，本质是模拟人类的注意力习惯，比如我们看一张图时会优先关注主体，读一句话时会抓住核心实词。

## 二、公式拆解：Query、Key、Value
注意力在工程上最终落地成一个公式。
![公式不长，但每个零件都有它存在的道理。](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788276168187-c70191e1-0929-4142-8438-807b3fb8a9ac.png)

### 2.1 先回忆一个数学工具：点积
两个向量 做点积：
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788278415780-94c2185e-cb0d-418b-b579-c5e2a77e4555.png)

这个式子的妙处在于，它把"两个向量像不像"翻译成了一个数：

+ 俩向量方向差不多（夹角小，cosθ 接近 1）→ 点积**很大**
+ 互相垂直、八竿子打不着 → 点积约等于 **0**
+ 方向完全拧着来 → 点积是负数
  ![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788278587531-1e5b5d58-176c-4eff-adec-d856334f7f26.png)

那为什么这件事对 NLP 重要？因为词嵌入（embedding）技术有个核心假设：**语义相近的词，在高维空间里的向量方向也相近**。既然"方向一致 ≈ 语义相近"，那点积就成了测量"两个词关系近不近"的现成尺子。

### 2.2 三个角色：Query、Key、Value
注意力机制里有三个主角，用"逛搜索引擎"来打比方最顺：

+ **Query（查询向量）**：你在搜索框里敲的那句话——"我现在想找什么"。
+ **Key（键向量）**：每条搜索结果挂在外面的标题和摘要——专门用来跟你的搜索词对暗号。
+ **Value（值向量）**：点进搜索结果之后看到的正文——你真正想搬走的内容。

整个计算过程就是：拿 Query 去和每条 Key 挨个对一遍暗号（算相似度），对得越上的，它对应的 Value 就被搬得越多；最后把所有 Value 按"搬运比例"搅和在一起，就是输出。

<font style="color:rgb(15, 17, 21);">注意力的精髓不是“选最优”，而是“分蛋糕”。每个候选都有份，只是切的大小不一样。只不过有人拿得多、有人拿得少。这个设计最牛的地方在于，它让整个计算过程才能处处求导，梯度才能一路顺畅地传回去，反向传播的时候梯度才能畅通无阻，模型才能学得动。</font>



### 2.3 三步走战略
拆开看，注意力计算拢共三步：
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788279132325-547058a6-da62-41e5-84da-8a22b6fb47e2.png)

**① 算分**：Query 和每一个 Key 点积，得到一串还没经过任何处理的相关性分数。

**② 归一**：这串分数送进 softmax，压成一个总和为 1 的分布——含义从"谁更相关"变成了"每家各占几成"。

**③ 混合**：按各自占比对 Value 加权求和，得到最终输出。

### 2.4 √d_k 是干嘛的
标准公式里，点积之后要除以一个 $ \sqrt{d_k} $（$ d_k $ 是 Key 向量的维度）。

问题出在哪：维度越高，点积的绝对值越大。分数一大，导致softmax函数进入饱和区，梯度消失。为了解决这个问题，引入缩放因子$ \sqrt{d_k} $来缩小点积结果，使softmax函数保持敏感。实验表明，这个缩放因子可以有效防止梯度消失。



### 2.5 softmax：从"打分"到"分账"
softmax 的作用一句话就够：**把一堆可正可负、有大有小的原始分数，变成一份加起来正好 100% 的"分账方案"**。


![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788279288728-00ac7af0-ffb8-4a81-aa03-9aa839d8d085.png)

## 三、注意力机制代码实现
原理讲了一堆，落到 PyTorch 里其实就一个函数，短到让人有点不好意思：

```python
import math
import torch


def attention(q, k, v, dropout=None):
    """
    缩放点积注意力（Scaled Dot-Product Attention）的最简实现。

    约定 q / k / v 的最后两维是 (序列长度, 向量维度)，
    前面可以带 batch 维、head 维，矩阵乘会自动广播处理。
    """
    # d_k：Key 向量的特征维度，取 k 的最后一维。
    # 待会要除以 sqrt(d_k)，把点积的数值尺度压回正常区间，
    # 免得 softmax 被顶进梯度几乎为零的饱和区。
    d_k = k.size(-1)

    # 第一步：计算相关性得分。
    # k.transpose(-2, -1) 把 k 的最后两维对调，
    # 于是 (..., seq_q, d_k) @ (..., d_k, seq_k) -> (..., seq_q, seq_k)，
    # 结果矩阵的第 i 行第 j 列，就是"第 i 个 query 对第 j 个 key"的原始得分。
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k)

    # 第二步：沿最后一维做 softmax。
    # 含义：对每个 query 来说，它分给所有 key 的权重加起来恰好等于 1。
    p_attn = torch.softmax(scores, dim=-1)

    # 训练阶段可选：对注意力权重做 dropout，抑制过拟合。
    if dropout is not None:
        p_attn = dropout(p_attn)

    # 第三步：权重与 Value 相乘再求和，相当于"按份搬运信息"，
    # 输出的每个位置都混入了全序列的上下文。
    return torch.matmul(p_attn, v)
```

Attention 是挑重点，就算文本比较长，也能从中间抓住重点，不丢失重要的信息。下图红色的预期就是被挑出来的重点。

## 四、自注意力机制(Self-Attention)
### 4.1 它和前面讲的注意力有啥区别
前面说的注意力，Query 和 Key 通常来自**两拨数据**。拿机器翻译举例：解码端拿着"当前生成到哪儿了"的状态当 Query，去编码端的中文句子特征（Key/Value）里查信息——这是跨序列的查询。

自注意力（Self-Attention）只有一个改动：**Q、K、V 全部来自同一个输入**。句子里的每个词既是提问者，也是被提问者，大家互相打听一圈。所以它也常被叫作"内部注意力"。

### 4.2 为什么需要这种"互相打听"
看一个经典的坑：

> The trophy didn't fit into the suitcase because it was too big.
>

`it` 指的是 `trophy`（奖杯太大塞不进箱子），而不是离它更近的 `suitcase`。人靠常识秒懂，但模型如果只盯着 `it` 前后两三个词看，很容易猜错——正确答案藏在句子更靠前的位置。中文里这种坑一样不少："**快递放进了储物柜，因为它实在太大了**"——"它"指快递还是储物柜？也得通读全句才敢下结论。

自注意力的存在就是为了解决这个问题：**让每个词都和全句所有词算一遍相关性**，不管目标隔多远，都能直接建立联系。


![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788279948661-237c8183-a8e0-4cf3-bf10-160800f519eb.png)

### 4.3 为什么要先做一次线性变换
这里有个容易忽略的设计：算注意力之前，每个词的向量要先分别乘以三个权重矩阵，而不是拿原始 embedding 直接点积。

核心原因是：**同一个词，"出门提问"和"在家被问"时应该拿出两副面孔**。

还拿指代举例：当 `它` 以 Query 的身份出发时，需要携带"我在找一个前文出现过的事物"这种探测信息；而当 `快递` 以 Key 的身份待命时，需要亮出"我是个实体名词、前面被提到过我"这种可被匹配的特征。两种诉求完全不同，一套向量伺候不了两个角色，于是配上三套可训练的投影矩阵 $ W_Q $、$ W_K $、$ W_V $：

于是每个词都被加工成三个向量，本质上都是"原始词向量 × 对应权重矩阵"：

**这层线性变换带来的好处有三个：**

1. 特征提取：全连接层可以看作是一种特征提取工具，它能够将原始词向量转换为更高级的语义表示，从而更好地捕捉句子中的上下文信息；
2. 参数学习：全连接层的参数可以通过训练过程进行优化，使得模型能够根据任务需求自动调整词向量的表示，从而提升模型的性能。
3. 注意力权重：注意力机制的核心是计算注意力权重，这些权重决定了每个词在上下文中的重要性。通过全连接层，可以更好地计算这些权重，使得模型能够更准确地捕捉到句子中的重要信息。增强模型的表达能力、灵活性。

### 4.4 完整的计算链路
1. 每个词都会被编码为三个向量：Query（查询）、Key（键）和Value（值）。这些向量是通过将原始词嵌入分别乘以三个不同的权重矩阵得到的。

### 4.5 自注意力机制(Self-Attention)代码实现
```python
import torch
import torch.nn as nn


class SelfAttention(nn.Module):
    """自注意力机制：Q、K、V 由同一份输入投影而来。"""

    def __init__(self, hidden_dim):
        super().__init__()
        self.hidden_dim = hidden_dim
        # 三个互不共享参数的线性层，
        # 分别学习"怎么提问 / 怎么应答 / 怎么贡献内容"
        self.q_linear = nn.Linear(hidden_dim, hidden_dim)
        self.k_linear = nn.Linear(hidden_dim, hidden_dim)
        self.v_linear = nn.Linear(hidden_dim, hidden_dim)

    def forward(self, x):
        # x: (batch, seq_len, hidden_dim)
        # 同一份输入走三条路，得到三个角色
        q = self.q_linear(x)
        k = self.k_linear(x)
        v = self.v_linear(x)

        # 核心计算复用前面写好的 attention 函数
        return attention(q, k, v)


# 快速验证：batch=3，每句 2 个词，词向量 4 维
x = torch.rand(3, 2, 4)
net = SelfAttention(4)
out = net(x)
print(out.shape)  # torch.Size([3, 2, 4]) 
```

## 五、多头自注意力机制(Multi-Head Self-Attention) 多角度看问题，信息更全面
### 5.1 单个注意力头的盲区
一个注意力头只学一套 $ W_Q $、$ W_K $、$ W_V $，也就意味着它只擅长捕捉**一种**词与词的关系。但语言里的关系是五花八门的，看这句：

> 「老王昨晚在群里发了个两百块的红包」
>

这句话里至少藏着三层结构：

+ **动作链**：`发` 这个动作连着发出者 `老王` 和对象 `红包`
+ **限定信息**：`昨晚` 框定时间，`群里` 框定地点
+ **属性描述**：`两百块` 说明红包的额度

<!-- 这是一张图片，ocr 内容为： -->
![](images/多头注意力-结构总览.png)<!-- 这是一张图片，ocr 内容为： -->
![指望一个头把这些全抓住，就像让一个人同时盯三个监控屏幕——顾得上这头就顾不上那头。多头注意力的解决方案很直接：派一组"专员"，每人盯一块，最后开会把情报汇总。](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788281650058-d1a6f08d-5e58-471f-a28e-c257ced1158e.png)

对应到这句话，理想的分工可能是：

+ 第一个注意力头A锁定 `老王` → `发` → `红包` 这条主谓宾主线
+ 第二个注意力头B 盯住 `昨晚`、`群里` 这类时空状语
+ 第三个注意力头C关心 `两百块` 对 `红包` 的修饰

一句话概括多头的好处：**多个视角并行开工，模型的表达容量直接翻倍**。

### 5.2 "多头"的实现：就是切蛋糕
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788281768517-7bcb25f4-581b-409f-9c80-600e99cb0c39.png)

实现上并没有什么黑科技，就是在 $ d_{model} $ 这个维度上**均匀切分**：Q、K、V 各自被切成 n 段，每一段独立跑一遍注意力，互不干扰。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1788281910511-9c0b5f78-ee7b-470d-a1fa-61193e0ac42a.png)

所谓的头，其实就是把QKV矩阵按d_model维度进行了切分，再减少了单次计算量，还提升了并行计算速度.

比如：定义的词向量维度是512维，定义了4个头，在多头注意力计算过程中，会把512除以4，每个头就是128维，这四个头单独计算QKV。

每个头都会输出一个结果，代表它从某个角度看到的词与词之间的关系。最后，这些结果会被拼接在一起。

这样做的好处是：模型可以从多个维度去理解语言，而不是局限于单一视角。

```python
from torch import nn
class MultHeadedAttention(nn.Module):
    def __init__(self, d_model,n_head,dropout=0.1):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

        #d_model 必须被 n_head 整除
        assert d_model % n_head == 0
        self.d_token = d_model // n_head # 每个头分到的维度
        self.n_head = n_head

        # 三个投影层。bias=False 是 Transformer 的通行做法：
        self.q_linear = nn.Linear(d_model,d_model,bias=False)
        self.k_linear = nn.Linear(d_model,d_model,bias=False)
        self.v_linear = nn.Linear(d_model,d_model,bias=False)
    	# 各头结果拼接后，再过一层线性做信息融合
        self.linear = nn.Linear(d_model,d_model,bias=False)
    def forward(self,q,k,v):
        #分头的主要目的是让模型能够同时关注输入序列的不同部分，从而捕捉更丰富的特征
        #q,k,v shape ==> batch_size,seq_len,d_mdoel
        n_batchs = q.size(0)
        q_seq_len = q.size(1)
        k_seq_len = k.size(1)
        v_seq_len = v.size(1)
        # (batch_size, seq_len, d_model) ===> (batch_size, seq_len, n_head, d_token)
        # 其中 n_head 是头的数量，d_token 是每个头的维度
        # 为了方便计算，需要将头的维度移到前面，变成 (batch_size, n_head, seq_len, d_token)
        # 矩阵运算（如 torch.matmul）通常对最后两个维度进行操作。
        # 将头的维度移到前面后，可以直接对 seq_len 和 d_token 维度进行矩阵乘法
        q = self.q_linear(q).view(n_batchs,q_seq_len,self.n_head,self.d_token).transpose(1,2)
        k = self.k_linear(k).view(n_batchs,k_seq_len,self.n_head,self.d_token).transpose(1,2)
        v = self.v_linear(v).view(n_batchs,v_seq_len,self.n_head,self.d_token).transpose(1,2)

        #计算注意力
        att = attention(q,k,v,self.dropout)
        #拼接
        #contiguous()确保张量在内存中是连续存储的，提高计算效率；
        #(batch_size, n_head, seq_len, d_token)=>(batch_size, seq_len, n_head, d_token)=>(batch_size, seq_len, d_model)
        concat = att.transpose(1,2).contiguous().reshape(n_batchs,-1,self.n_head * self.d_token)
        output = self.linear(concat)
        return output

mha = MultHeadedAttention(8,2)
q=k=v= torch.randn(2,3,8)
mha_out = mha(q,k,v)
print(mha_out)
print(mha_out.shape)
```

## 六、动手实战：给 CNN 装上注意力
**在 CNN 里嵌入多头自注意力，完成图像分类**

### 6.1 核心思路：把特征图"读"成一句话
CNN 卷积层吐出来的特征图形状是 `(N, C, H, W)`，乍一看和注意力要的 `(batch, seq_len, d_model)` 八竿子打不着。但只需要换一个看问题的角度：

+ 特征图上的每个空间位置 $ (h, w) $，看成句子里的一个"词"；
+ 这个位置上的 C 维通道特征，看成这个词的词向量。

这么一转换，特征图就变成了一条长度为 $ H \times W $、词向量维度为 C 的"句子"，正好塞进自注意力。

### 6.2 模型搭建
```python
import torch
import torch.nn as nn

class CNNWithAttention(nn.Module):
    def __init__(self,num_classes):
        super().__init__()
        # 轻量卷积主干：五层卷积逐步加深通道数，
        # Conv 后面统一 BN + ReLU 保证训练稳定
        self.conv_layers = nn.Sequential(
            nn.Conv2d(3,16,3,bias=False),
            nn.BatchNorm2d(16),
            nn.ReLU(),
            nn.MaxPool2d(2),
            
            nn.Conv2d(16,32,3,bias=False),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2),
            
            nn.Conv2d(32,64,3,bias=False),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            
            nn.Conv2d(64,128,3,bias=False),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            
            nn.Conv2d(128,256,3,bias=False),
            nn.BatchNorm2d(256),
            nn.ReLU()
        )
        #self.attention = nn.MultiheadAttention(embed_dim=256,num_heads=4)
        # 注意力层：每个空间位置当一个 token，256 是 token 的特征维度
        self.attention = MultHeadedAttention(d_model=256,n_head=4)
        #特征图空间尺寸为 20×20，
        # 展平成 400*256 维后接分类头
        self.fc = nn.Linear(400*256,num_classes)
    def forward(self,x):
        x = self.conv_layers(x)
        #shape: [1,256,20,20] N C H W
        x = x.permute(0,2,3,1) #shape: [1,20,20,256] N H W C
        x = x.reshape(x.size(0),-1,x.size(-1)) #shape: [1,400,256] N V C
        #调整为(batch_size,seq_len,embedding_dim)
        #多头自注意力 q=k=v=x
        x= self.attention(x,x,x) #shape: [1,400,256]
        x = x.reshape(-1,400*256) #shape: [1,102400]
        x = self.fc(x)
        return x

# 创建模型实例
model = CNNWithAttention(6)
x = torch.randn(1,3,112,112)
y = model(x)
print(y.shape)
```

为什么要费劲加这层注意力？因为卷积核天生是"近视眼"——一个 3×3 的卷积一次只能看到周围一小片区域，想让相隔很远的位置产生联系，得靠很多层卷积慢慢把感受野堆大。而**注意力一步就能让图上任意两个位置直接交互**，等于给 CNN 补上了全局视野。比如判断"果皮颜色和果柄形状是不是属于同一个水果"这种需要远距离配合的特征，注意力就比纯卷积从容得多。
