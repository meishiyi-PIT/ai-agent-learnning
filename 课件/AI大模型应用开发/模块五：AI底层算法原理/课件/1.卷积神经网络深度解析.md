## 1. 全连接神经网络的"两大致命伤"
### 1.1 空间信息被"拍平"了---**<font style="color:rgb(6, 10, 38);">丢失了空间结构</font>**
想象你手里有一张 `200×200` 的彩色自拍，在喂给全连接网络之前，你得先把它拉成一个 `120000` 维的一维向量。这个操作相当于把一张照片扔进碎纸机——像素之间的空间邻居关系全丢了。

打个比方：你脸上左眼和右眼之间存在固定的空间约束（对称、距离），但在展开后的长向量里，左眼区域的像素可能排在索引 0~99，右眼区域的像素跑到索引 50000~50099 去了。网络看到的只是一堆"毫无空间上下文"的数字序列，它压根不知道谁和谁是邻居。

> 上图直观展示了：空间上紧挨的两个像素点，在展开的一维向量中相距甚远，空间关联性荡然无存。
>
> 图像不是一串彼此独立的数字，而是一种具有空间组织关系的数据。
>

### 1.2 参数爆炸——模型根本训不动
全连接层的另一个问题是**参数数量随图像尺寸平方级增长**。来算一笔账：

```plain
输入图片: 1000 × 1000 (彩色, 3通道)
展开后输入维度: 3 × 1000 × 1000 = 3,000,000
下一层隐藏单元: 1,000,000 个
参数总量: 3,000,000 × 1,000,000 = 3 × 10^12
```

3万亿个权重参数。要知道像 DeepSeek-V3 这种千亿级参数的模型已经需要几十张 H800 来训练了——消费级显卡遇到这种参数体量，可能连显存分配都撑不过去。

## 2. 卷积运算
### 2.1 卷积运算的本质——"滑动窗口 + 加权求和"
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785122079027-89586669-780d-46e7-ae2a-2deb86677a2d.png)

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/gif/21571931/1785290424892-8a42106d-0d48-42d9-aac5-b207b53ef0a0.gif)

**<font style="color:rgb(15, 17, 21);">直观理解</font>**<font style="color:rgb(15, 17, 21);">：拿着一个小方框（卷积核），在图片上从左到右、从上到下</font>**<font style="color:rgb(15, 17, 21);">滑动</font>**<font style="color:rgb(15, 17, 21);">，每停在一个位置，就把小方框里的数字和对应位置的像素数字相乘，最后把所有乘积加起来，作为新图片该位置的一个像素点。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785226434393-93493822-22d4-44c2-bf30-e2aaedc6cca0.png)

**卷积的步骤:**

1. 把一个 `K×K` 的卷积核（也叫滤波器、kernel）放在输入图像的左上角。
2. 卷积核的每个元素和图像对应位置的像素相乘。
3. 把乘积全加起来，得到输出特征图该位置的值。
4. 卷积核向右滑动一个步长，重复步骤 2-3。
5. 滑完一行后向下移动，继续，直到扫完整个图像。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787503482812-8e781aca-241a-41c1-ac9b-e3ad85226372.png)

<!-- 这是一张图片，ocr 内容为： -->
![这个卷积核就提取到右下线条的特征](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785306240049-ada827bb-b8a5-46dc-bcf4-a0430ec039a8.png)

**<font style="color:rgb(51, 51, 51);">图像的卷积运算是‌利用</font>****<font style="color:rgb(15, 17, 21);">一个可学习的“特征提取器”（卷积核）</font>****<font style="color:rgb(51, 51, 51);">在图像上滑动，通对局部像素进行“对应相乘再求和"(</font>****<font style="color:rgb(15, 17, 21);">加权求和</font>****<font style="color:rgb(51, 51, 51);">)，以提取图像特征的核心操作‌。‌‌</font>**

<!-- 这是一张图片，ocr 内容为： -->
![通过不同的卷积核来对图像进行不同的处理，得到不同的特征图，显示出来不同特征分布在图像的什么样的位置](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785318263099-5daad81f-8353-49bc-9822-aa320c5874d8.png)

**卷积不是“整张图一起看”，而是先从局部开始找规律。**<font style="color:rgb(6, 10, 38);">不同的卷积核找不同模式：横向边、竖向边、颜色、纹理；层数越深，简单模式越被组合成形状、部件与语义概念。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/63478851/1784619013467-0e35aa33-6c9f-42ff-97ca-9bdb60a6b8f6.png)



```python
import torch
import torch.nn as nn


# 1 张 灰度图，每张大小 32x32。
images = torch.randn(1, 1, 32, 32)
# 8 个卷积核，每个卷积核看 1 个输入通道，常见的卷积核大小是 3x3 或 5x5。
conv = nn.Conv2d(1, 8, kernel_size=3)
features = conv(images)

print("输入图片:", images.shape) #[1, 1, 32, 32]
print("卷积核权重:", conv.weight.shape)  # [8, 1, 3, 3]
print("输出特征图:", features.shape)     # [1, 8, 30, 30]
```

### 2.2 偏置项——卷积也有 bias
#### 卷积层中的 bias
卷积层的 bias 是每个输出通道对应的可学习标量参数。卷积核完成局部加权求和后，bias 会被广播加到该输出通道的所有空间位置上。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785138671216-3289ca5b-dffc-4058-a17a-44199954bdc7.png)

如果某层卷积的 `out_channels=16`，通常就有 16 个 bias。它的作用是给每个输出特征通道提供一个可学习的基准偏移。

卷积层的 bias 不作用在原始图片上，也不是在调图片亮度。更准确地说，它是在卷积核算完之后，给某一个输出通道的所有位置统一加上一个标量。

如果 `out_channels=8`，就有 8 个 bias。第 1 个 bias 加到第 1 张输出特征图的所有位置，第 2 个 bias 加到第 2 张输出特征图的所有位置，以此类推。

每个输出通道对应一个偏置值——有多少个卷积核（输出通道），就有多少个偏置。



<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/63478851/1784619074904-1c7f1565-db26-48ae-be9c-ffcbe7d7a5b7.png)



#### 卷积与全连结对比
**<font style="color:rgb(51,51,51);">卷积的优点</font>**：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785309830061-0050b7ae-1097-4787-8420-794abeebf614.png)

+ **权重共享**：<font style="color:rgb(51,51,51);">用一个卷积核去扫描一张图，卷积核的参数就叫权重。</font><font style="color:rgb(15, 17, 21);">同一个卷积核在输入数据的不同位置滑动时，</font>**<font style="color:rgb(15, 17, 21);">权重是完全相同的</font>**<font style="color:rgb(15, 17, 21);">。一个用于检测“边缘”的卷积核，会在整张图片的所有位置去寻找边缘，而不是在每个位置重新学习一个不同的边缘检测器。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785309861336-d1b88c1c-8295-40ae-973d-4c5474bb2ce7.png)

+ **<font style="color:rgb(15, 17, 21);">局部连接(减少网络的参数量)</font>**：<font style="color:rgb(15, 17, 21);">卷积核每次只“看”输入图像中</font>**<font style="color:rgb(15, 17, 21);">很小的一小块区域</font>**<font style="color:rgb(15, 17, 21);">（比如 </font><font style="color:rgb(15, 17, 21);">3×3</font><font style="color:rgb(15, 17, 21);"> 的方块），而不是一下子看完整张图。</font>

<font style="color:rgb(15, 17, 21);">在全连接网络中，每个神经元都与上一层的所有神经元相连。对于一张</font><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">1000</font><font style="color:rgb(15, 17, 21);">×</font><font style="color:rgb(15, 17, 21);">1000</font><font style="color:rgb(15, 17, 21);">1000</font><font style="color:rgb(15, 17, 21);">×</font><font style="color:rgb(15, 17, 21);">1000</font><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">的图像，输入层就有100万个像素，如果下一层有1000个神经元，参数总量将达到惊人的</font><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">10</font><font style="color:rgb(15, 17, 21);">9</font><font style="color:rgb(15, 17, 21);">1</font><font style="color:rgb(15, 17, 21);">0</font><font style="color:rgb(15, 17, 21);">9</font><font style="color:rgb(15, 17, 21);">（10亿）。</font>

**<font style="color:rgb(15, 17, 21);">卷积的做法</font>**<font style="color:rgb(15, 17, 21);">：卷积核通常很小（如 3×3 或 5×5），每个神经元只关注输入数据的一个局部区域（感受野）。</font>

**<font style="color:rgb(15, 17, 21);">结果</font>**<font style="color:rgb(15, 17, 21);">：参数数量急剧减少，大幅降低了内存占用和计算量，使得训练深层网络成为可能。</font>

```python
import torch
from torch import nn

# 1. 超参数写死：只比较参数量，不做训练。
image_channels = 3
image_height = 200
image_width = 200
class_count = 10

# 2. 全连接层：需要把整张图片拍平成一个超长向量。
full_connection = nn.Linear(image_channels * image_height * image_width, class_count)
full_connection_params = sum(param.numel() for param in full_connection.parameters())

# 3. 卷积层：只看 3x3 局部窗口，参数量和图片宽高无关。
convolution = nn.Conv2d(in_channels=3, out_channels=1, kernel_size=3)
convolution_params = sum(param.numel() for param in convolution.parameters())

# 4. 打印对比结果。
print("全连接参数量:", full_connection_params)
print("卷积层参数量:", convolution_params)
print("结论: 卷积层靠局部连接和权重共享，把参数量明显压小。")
```

```python
import torch
from torch import nn

# 1. 模拟一张 1 通道 4x4 ‘假图片’。
image = torch.randn(1, 1, 4, 4)

# 2. 卷积层：3x3 卷积核有 9 个权重，再加 1 个 bias。
conv = nn.Conv2d(in_channels=1, out_channels=1, kernel_size=3)
conv_out = conv(image)

print("卷积参数:")
print("  weight 数量:", conv.weight.numel())
print("  bias 数量:", conv.bias.numel())
print("  输出形状:", conv_out.shape)

# 3. 全连接层：把 4x4 图片拍平成 16 维，再输出 4 维。
flat_image = torch.flatten(image)
fc = nn.Linear(16, 4)
fc_out = fc(flat_image)

print("全连接参数:")
print("  weight 数量:", fc.weight.numel())
print("  bias 数量:", fc.bias.numel())
print("  输出形状:", fc_out.shape)
```

### 2.3 填充（Padding）——别让特征图越卷越小
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785222911754-911c95a1-dd9d-45dc-9f43-bd837288810c.png)

```python
import torch
from torch import nn

# 1. 模拟一张 1 通道 4x4 ‘假图片’。
image = torch.randn(1, 1, 4, 4)

# 2. 卷积层：5*5 卷积核。
conv = nn.Conv2d(in_channels=1, out_channels=1, kernel_size=5)
conv_out = conv(image)
print(conv_out)
```

<font style="color:rgb(51, 51, 51);">‌</font>**<font style="color:rgb(51, 51, 51);background-color:rgba(0, 0, 0, 0);">卷积padding就是在</font>**<font style="color:rgb(15, 17, 21);">输入图像（或特征图）的</font>**<font style="color:rgb(15, 17, 21);">外围补上一层（或多层）额外的</font>****<font style="color:rgb(51, 51, 51);background-color:rgba(0, 0, 0, 0);">"假像素"（通常是0）</font>**<font style="color:rgb(51, 51, 51);">‌，主要目的是防止通过卷积运算后</font><font style="color:rgb(15, 17, 21);">特征图</font><font style="color:rgb(51, 51, 51);">越变越小，同时让边缘像素也能被充分计算到</font>。

在 卷积神经网络 中，padding 常用于保持空间尺寸、减少边缘信息损失，并让深层卷积网络可以连续堆叠更多层。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785221729540-d0d9fb3d-86bf-4f77-bfe5-0b900f1d3f46.png)

```python
import torch
from torch import nn

# 1. 模拟一张 1 通道 4x4 ‘假图片’。
image = torch.randn(1, 1, 4, 4)

# 2. 卷积层：5*5 卷积核。
conv = nn.Conv2d(in_channels=1, out_channels=1, kernel_size=5,padding=1)
conv_out = conv(image)
print(conv_out)
```

**padding 的核心价值是“保护边缘”和“控制尺寸”**

很多商品图的关键信息并不只在中心。比如手机边框、衣服袖口、鞋底轮廓，经常出现在图片边缘。如果不加 padding，边缘像素被卷积核覆盖的次数会更少，信息很容易被削弱。

padding 还有一个工程价值：让多层卷积可以连续堆叠。如果每卷一层尺寸就小一圈，网络还没学到高级特征，特征图可能已经缩得太小了。

```python
import torch

# 模拟一张 1 通道 4x4 ‘假图片’。
data = torch.randn(1, 1, 4, 4)

# 对比有无 padding 的结果
# padding=0: 输出 2×2
conv_no_pad = torch.nn.Conv2d(in_channels=1, out_channels=1, kernel_size=3,padding=0)
result_no_pad = conv_no_pad(data)
print(f"无填充输出: {result_no_pad.shape}")  # [1, 1, 2, 2]

# padding=1: 输出 4×4（补一圈零，尺寸不变）
conv_pad = torch.nn.Conv2d(in_channels=1, out_channels=1, kernel_size=3,padding=1)
result_pad = conv_pad(data)
print(f"有填充输出: {result_pad.shape}")  # [1, 1, 4, 4]
```

### 2.4 步长（Stride）——一次滑多远
**步长:****<font style="color:rgb(15, 17, 21);">卷积核在输入图像上每次滑动移动的像素个数</font>**

<font style="color:rgb(51, 51, 51);">按照步长为1来移动卷积核，计算特征图如下所示：</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785291595663-b505a569-b499-47be-b411-5fc0ea11bd23.png)

<font style="color:rgb(51, 51, 51);">如果我们把 Stride 增大为2，也是可以提取特征图的，如下图所示：</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785291836951-0aedbfcf-2caf-4e58-87f5-b8d1a74a96f2.png)

步长控制卷积核每次移动的像素数。步长越大，输出越小，计算量也越小——当然，代价是丢掉了更多细节。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785226679782-f0044a69-f036-4282-a3e8-7a700d253f8b.png)

总结成一句话：

> 卷积核大小决定“一次读取几个点”，步长决定“这些点在原图上相隔多远”。
>

**stride：控制特征图缩小速度**

```python
import torch
from torch import nn

# 1. 模拟一张 RGB 商品图。
image = torch.randn(1, 3, 32, 32)

# 2. stride=1：卷积核移动更密，输出尺寸保持 32x32。
conv_stride_1 = nn.Conv2d(3, 8, kernel_size=3, stride=1, padding=1)

# 3. stride=2：卷积核每次跳 2 格，输出尺寸减半。
conv_stride_2 = nn.Conv2d(3, 8, kernel_size=3, stride=2, padding=1)

# 4. 打印输出形状，观察 stride 对空间尺寸的影响。
print("输入形状:", image.shape) #1, 3, 32, 32
print("stride=1 输出:", conv_stride_1(image).shape) #1, 8, 32, 32
print("stride=2 输出:", conv_stride_2(image).shape) #1, 8, 16, 16
```

### 2.5 感受野——"站在越高的地方，看得越远"
**<font style="color:rgb(15, 17, 21);">感受野</font>**<font style="color:rgb(15, 17, 21);">：卷积神经网络中，</font>**<font style="color:rgb(15, 17, 21);">输出特征图上的一个点</font>**<font style="color:rgb(15, 17, 21);">，对应到</font>**<font style="color:rgb(15, 17, 21);">原始输入图像上的区域大小</font>**<font style="color:rgb(15, 17, 21);">。</font>  
<font style="color:rgb(15, 17, 21);">通俗说：</font>**<font style="color:rgb(15, 17, 21);">输出层的一个像素，能“看到”输入层的多大范围。</font>**

<font style="color:rgba(0, 0, 0, 0.9);">比如:卷积3*3对应的感受野大小就是。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785227492162-36ce045b-b2e4-4d22-a7aa-fec5f066f3d4.png)

<font style="color:rgba(0, 0, 0, 0.9);">而当通过两层3*3的卷积之后，感受野的大小将会增加到5*5。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785227434600-c1efe5b9-0850-401e-a7e9-743772ade7d3.png)

+ 第 1 层（第 1 层卷积）：你只能看到窗外 `3×3` 格子大小的区域。
+ 第 2 层（第 2 层卷积）：之前 `3×3` 的输出变成了输入，每个像素又来自原始图像的 `3×3` 区域，所以你实际看到了原始图像的 `5×5` 区域。

**<font style="color:rgba(0, 0, 0, 0.9);">因此，当增加卷积网络深度的同时，感受野将会增大，输出特征图中的一个像素点将会包含更多的图像语义信息。</font>**

**核心结论**：网络越深，感受野越大，单个神经元"知道"的上下文就越丰富。这就是为什么深层网络能学到更抽象的语义特征——浅层看纹理，深层看"整个物体的概念"。

> 两个输入通道各配一个 `2*2` 的卷积核，两个结果逐元素相加，得到单通道输出。这里的核心是"逐通道卷积 → 求和"。

#### 三通道输入（RGB 的标准情况）
真实世界的图片通常是 RGB 三通道的（3×H×W），卷积核也需要跟着"升级"。

**核心原则两条：**

1. **卷积核的通道数 = 输入特征图的通道数**
2. **卷积核的个数 = 输出特征图的通道数**

> RGB 图 = 3 个输入通道。卷积核自动扩展为 `3×3×3`——每个输入通道配一个 `3×3` 的二维核，三个结果求和后形成单通道输出。`1` 个这样的"三维卷积核"（严格说是"体卷积核"）在图中简写成 `3×3×3`。

增加卷积核的数量就行了。**每个卷积核独立运算，各自产生一个输出通道**。

### 2.7 批量操作——一次算一批
为了充分利用 GPU 的并行能力，实际训练中会一次性喂给模型一个 mini-batch（比如 32 或 64 张图），输入形状变成 `N × C_in × H_in × W_in`。

#### 卷积核参数
卷积层权重的形状是：

<!-- 这是一张图片，ocr 内容为： -->

```plain
nn.Conv2d(
    in_channels=3,
    out_channels=64,

```

卷积核参数形状为：

```plain
64 × 3 × 3 × 3
```

含义是：

```plain
64：有64个完整卷积核，产生64个输出通道
3：每个完整卷积核包含3个输入通道切片
3×3：每个切片的空间大小
```

需要特别注意：

> 卷积核形状中没有 (N) 维。无论一次输入1张、32张还是64张图片，卷积层的参数数量都不变。
>

#### batch 维度上的权重共享
对于批次中的每张图片，都使用同一个权重张量 (W)：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/63478851/1784800541947-010a181b-b0f3-44d0-93a4-d63207134334.png)



也就是说：

```plain
图片1使用W
图片2也使用W
……
图片N仍然使用W
```

不是为32张图片准备32套卷积核，而是：

```plain
32张图片 × 同一套卷积核参数
```

GPU 会把这些图片对应的大量卷积运算并行执行，从而提高计算效率。

#### 输出形状
卷积完成后，批次维度仍然保留：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/63478851/1784800558329-5052cd16-0882-4b17-92c4-98852b6ae0ab.png)  


例如输入批次为32，卷积层输出64个通道，则输出可能是：

```plain
Y.shape = 32 × 64 × H_out × W_out
```

其中每张输入图片都有自己独立的64通道输出。

一句话总结：

> 批次中的图片彼此独立计算，但共享同一套卷积核参数；`N` 决定一次处理多少张图片，不会改变卷积层的参数形状和参数数量。
>

```python
bias_count = conv.bias.numel()

print("bias 参数量:", bias_count)
print("总参数量:", weight_count + bias_count)
```

### 2.8 特征图尺寸怎么算？
#### 特征图尺寸由哪些超参数决定
特征图尺寸指卷积层输出张量在空间维度上的高和宽，通常写作 `H_out x W_out`。它由输入尺寸、卷积核大小、padding、stride 共同决定。

在工程中，尺寸计算非常关键，因为后一层网络的输入形状必须和前一层输出形状对齐，否则模型会在运行时报 shape mismatch。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785227086356-f9b34b1f-6529-476a-8b64-4d8c7bda2a5e.png)

**尺寸公式其实是在问“窗口能放下几次”**

输出特征图的宽高，不是框架随便给的，而是由三个动作决定的：卷积核有多大、边缘补了多少圈、每次滑多远。

可以把输入图片想成一排货架，卷积核是一把固定宽度的尺子。padding 相当于在货架两边加空位，stride 相当于尺子每次移动几格。最终能放下多少个窗口位置，输出特征图就有多大。

## 3. 池化：给特征图做一次"瘦身"
池化（Pooling）做的事情非常直觉：把特征图的一小块区域用一个统计量（最大值或平均值）概括，从而压缩空间尺寸。

### 最大池化（Max Pooling）
在每个滑动窗口里取最大值,这样模型<font style="color:rgb(15, 17, 21);">更关注局部区域最显著的特征（如边缘、纹理）。</font>这是 CNN 中最常用的池化方式。

<font style="color:rgb(15, 17, 21);">最大池化的核心作用：</font>**<font style="color:rgb(15, 17, 21);">在局部区域内，只保留响应最强烈、最显著的特征，并忽略掉其他较弱的信息。</font>**

> `2×2` 窗口，stride=2：每个窗口取最大值，空间尺寸直接减半。
>



<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/63478851/1784619169801-588f4689-b1b0-4caf-9c48-f7b41b5a0de0.png)  
**最大池化的几个关键特性：**

+ **零参数**：没有权重，没有偏置，不需要训练。
+ **通道独立**：每个通道单独池化，通道数不会变（`C_in = C_out`）。
+ **保留显著特征**：取最大值的本质是"只留最强的信号"。边缘、纹理等强响应区被保留，微弱的噪声被丢掉了。

图示：最大池化只留下窗口里的最强响应

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/__mermaid_v3/cbadf3f8616f53001771e2929dc3e6d9.svg)

最大池化：保留强响应，压缩特征图

```python
import torch
from torch import nn

# 1. 模拟 1 张图片经过卷积后得到的特征图。
features = torch.randn(1, 3, 32, 32)

# 2. 最大池化：每个 2x2 小窗口取最大值，宽高减半。
max_pool = nn.MaxPool2d(kernel_size=2)
pooled_features = max_pool(features)

# 3. 池化不改变通道数，只压缩空间尺寸。
print("池化前:", features.shape)  #1, 3, 32, 32
print("池化后:", pooled_features.shape)  #1, 3, 16, 16
```

输出空间尺寸会从 `32x32` 变成 `16x16`。通道数不变，宽高减半。

```python
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()

        #特征提取器 
        #Conv → ReLU → Pool 重复堆叠
        #卷积提取局部模式，ReLU 引入非线性，池化降低空间分辨率并扩大有效视野。
        self.conv1 = nn.Sequential(
            # 第一个卷积块
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),
        )

        self.conv2 = nn.Sequential(
            # 第二个卷积块
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),
        )

        self.conv3 = nn.Sequential(            
            # 第三个卷积块
            nn.Conv2d(32, 64, kernel_size=3),
            nn.ReLU()
        )

        self.conv4 = nn.Sequential(            
            # 第三个卷积块
            nn.Conv2d(64, 128, kernel_size=3),
            nn.ReLU()
        )

        #分类器 处理卷积层提炼后的高层特征，最终输出类别得分
        #Flatten 特征图拉成一维向量
        #Linear映射到类别数维度
        #Softmax：推理时转成概率分布
        self.fc = nn.Sequential(
            # 展平层
            nn.Flatten(),
            # 全连接层
            nn.Linear(128 * 4 * 4, num_classes),
            nn.Softmax(dim=1)
        )

    def forward(self, x):
        conv_out = self.conv1(x)
        conv_out = self.conv2(conv_out)
        conv_out = self.conv3(conv_out)
        conv_out = self.conv4(conv_out)
        out = self.fc(conv_out)
        return out


# 测试代码
if __name__ == "__main__":
    data = torch.randn(1, 3, 32, 32)
    model = SimpleCNN()
```

```python
import torch
from torch import nn

class LeNet5(nn.Module):
    def __init__(self):
        super().__init__()
        #特征提取器 Conv → ReLU → Pool 反复出现
        #卷积提取局部模式，ReLU 引入非线性，池化降低空间分辨率并扩大有效视野。
        self.conv1 = nn.Sequential(
            nn.Conv2d(in_channels=3, out_channels=6, kernel_size=5, stride=1, padding=0),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.conv2 = nn.Sequential(
            nn.Conv2d(in_channels=6, out_channels=16, kernel_size=5, stride=1, padding=0),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.flatten = nn.Flatten()
        
        self.fc1 = nn.Sequential(
            nn.Linear(400, 120),
            nn.ReLU()
        )
        
        self.fc2 = nn.Sequential(
            nn.Linear(120, 84),
            nn.ReLU()
        )
        
        self.fc3 = nn.Linear(84, 10)
        
    def forward(self, x):   
        out = self.conv1(x)
        out = self.conv2(out)
        out = self.flatten(out)
        out = self.fc1(out)
        out = self.fc2(out)
        
        logits = self.fc3(out)
  
        return logits

if __name__ == '__main__':
    net = LeNet5()
    data = torch.randn(1, 3, 32, 32)
    output = net(data)
```

```python

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torch.utils.tensorboard import SummaryWriter
from torchvision import datasets, transforms
from lenet import LeNet5
import tqdm


# 指定日志目录
writer = SummaryWriter(log_dir='logs')

# 1. 判断是否使用CUDA
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f'Using device: {device}')
# 2. 准备数据
train_set = datasets.CIFAR10(root='cifar10', train=True, download=True, transform=transforms.ToTensor())
test_set = datasets.CIFAR10(root='cifar10', train=False, download=True, transform=transforms.ToTensor())
train_loader = DataLoader(dataset=train_set, batch_size=100, shuffle=True)
test_loader = DataLoader(dataset=test_set, batch_size=100, shuffle=False)
# 3. 创建模型
model = LeNet5()
model = model.to(device)
# 4. 确定损失函数
loss_fn = nn.CrossEntropyLoss()
# 5. 创建优化器 使用梯度下降算法 参数的更新
opt = torch.optim.Adam(model.parameters())

for epoch in range(100):
    # 6. 训练模型
    model.train()
    train_total_loss = 0
    for images, labels in tqdm.tqdm(train_loader, desc="train", total=len(train_loader)):
        # 将数据移动到设备
        images, labels = images.to(device), labels.to(device)
        outputs = model(images) # 前向传播
        loss = loss_fn(outputs, labels) # 计算损失

        opt.zero_grad() # 清空梯度
        loss.backward() # 反向传播 计算梯度
        opt.step() # 更新参数
        train_total_loss += loss.item()
    train_avg_loss = train_total_loss / len(train_loader)
    print(f'Epoch {epoch+1}, Loss: {train_avg_loss:.4f}')
    # 7. 测试模型
    model.eval()
    test_total_loss = 0
    test_total_acc = 0
    with torch.inference_mode(): 
        for images, labels in tqdm.tqdm(test_loader, desc="test", total=len(test_loader)):
            images, labels = images.to(device), labels.to(device)
            outputs = model(images)
            # 计算损失
            loss = loss_fn(outputs, labels)
            test_total_loss += loss.item()

            pred = torch.argmax(outputs, dim=1)
            acc = torch.eq(pred, labels).float().mean()
            test_total_acc += acc.item()

    test_avg_acc = test_total_acc / len(test_loader)
    print(f'Epoch {epoch+1} Test Accuracy: {test_avg_acc:.4f}')

    test_avg_loss = test_total_loss / len(test_loader)
    print(f'Epoch {epoch+1} Test Loss: {test_avg_loss:.4f}')
    # 记录数据
    writer.add_scalars('Loss/train', {'train_avg_loss': train_avg_loss,
    'test_avg_loss': test_avg_loss}, epoch)
    writer.add_scalar('Accuracy/test', test_avg_acc, epoch)
    # 8. 保存模型
    torch.save(model.state_dict(), f'D:/code/xwdev/model/mnist_net_{epoch+1}.pth')

```

## 5. CNN vs 全连接网络：核心差异总结
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785135915114-4ffefdd1-e6aa-4eb9-8ada-4801db172f98.png)

下面这张表描述了两者的本质差异：

| 维度 | 全连接网络 (FCNN) | 卷积神经网络 (CNN) |
| --- | --- | --- |
| **连接方式** | 每个输出连到所有输入 | 每个输出只连到局部窗口 |
| **参数数量** | `输入维 × 输出维`，随图片尺寸平方增长 | `C_out × C_in × K × K`，与图片尺寸无关 |
| **权重共享** | 每个连接独立参数 | 整张图共用同一组卷积核 |
| **空间结构** | 把图像"拍平"后空间信息丢失 | 天然保留二维空间结构 |
| **通道概念** | 无（输入是 N×V 的二维矩阵） | 有（输入是 N×C×H×W 的四维张量） |
| **计算量** | 参数多，计算密集 | 参数少，但大量中间特征图占用显存 |
| **适用场景** | 表格数据、文本分类 | 图像、视频等具有空间结构的数据 |
