## 过拟合、欠拟合与Dropout
<font style="color:rgb(13, 13, 13);">深度学习目标是训练出一个能够捕捉数据背后潜在规律的模型，使其不仅能够很好地拟合训练数据，还能对从未见过的新数据做出准确预测，这种能力被称为泛化能力。</font>

**<font style="color:rgb(51, 51, 51);">欠拟合</font>**<font style="color:rgb(51, 51, 51);">：模型未能充分学习到训练数据中的规律，</font><font style="color:rgb(15, 17, 21);">导致模型在训练集和测试集上的表现都很差</font><font style="color:rgb(51, 51, 51);">。常见原因是模型太简单、训练轮数太少、学习率不合适，或者输入特征被处理得太粗。</font>

**<font style="color:rgb(55, 65, 81);">过拟合：</font>**<font style="color:rgb(13, 13, 13);">不仅学到了数据中的真实规律，还将噪声也一并记住了。</font><font style="color:rgb(15, 17, 21);">导致</font><font style="color:rgb(55, 65, 81);">模型在训练集上表现很好，但在测试集或真实线上数据上表现明显变差。</font>

**<font style="color:rgb(86, 87, 114);">dropout是一种用于防止过拟合的技术。</font>**

**<font style="color:rgb(15, 17, 21);">dropout的本质：</font>**<font style="color:rgb(86, 87, 114);">每次训练迭代中随机</font>**<font style="color:rgb(15, 17, 21);">丢弃</font>**<font style="color:rgb(86, 87, 114);">一些神经元，</font><font style="color:rgb(51,51,51);">以减少模型的权重</font><font style="color:rgb(86, 87, 114);">。被</font>**<font style="color:rgb(15, 17, 21);">丢弃</font>**<font style="color:rgb(86, 87, 114);">的神经元将不参与前向传播和反向传播。</font>

![比如 nn.Dropout(p=0.5)，意味着这一层 50% 的神经元输出被乘以 0（直接消失）。这次丢弃是随机的。下一次迭代时，被丢掉的神经元会换一批。](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787649906481-4fa3d6d9-0f09-4174-b050-7602be203d41.png)

```python
import torch
from torch import nn

class LeNet5(nn.Module):
    def __init__(self,dropout_rate=0.5):
        super().__init__()
        #特征提取器 Conv → ReLU → Pool 反复出现
        #卷积提取局部模式，ReLU 引入非线性，池化降低空间分辨率并扩大有效视野。
        self.conv1 = nn.Sequential(
            nn.Conv2d(in_channels=3, out_channels=6, kernel_size=5, stride=1, padding=0),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.conv2 = nn.Sequential(
            nn.Conv2d(in_channels=6, out_channels=16, kernel_size=5, stride=1, padding=0),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.flatten = nn.Flatten()
        
        self.fc1 = nn.Sequential(
            nn.Linear(400, 120),
            nn.ReLU(),
            nn.Dropout(p=dropout_rate)
        )
        
        self.fc2 = nn.Sequential(
            nn.Linear(120, 84),
            nn.ReLU(),
            nn.Dropout(p=dropout_rate)
        )
        
        self.fc3 = nn.Linear(84, 10)
        
    def forward(self, x):   
        out = self.conv1(x)
        out = self.conv2(out)
        out = self.flatten(out)
        out = self.fc1(out)
        out = self.fc2(out)
        
        logits = self.fc3(out)
  
        return logits

if __name__ == '__main__':
    net = LeNet5()
    data = torch.randn(1, 3, 32, 32)
    output = net(data)
    print(output)

```

## 梯度消失与梯度爆炸
### 2.1梯度消失
<font style="color:rgb(51, 51, 51);">按直觉来说，神经网络越深，能表达的特征应该越丰富，效果自然越好。但实验很快打了所有人的脸：继续往下堆层数，</font>**训练误差**<font style="color:rgb(51, 51, 51);">不降反升。</font>

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787712974469-49bd6ba4-588f-447d-9f5c-8e78f49aef60.png)

<!-- 这是一张图片，ocr 内容为： -->
![这就导致网络的浅层（靠近输入端）无法有效地学习，整个网络的训练停滞不前。这就是“梯度消失”](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787885399524-a29140a5-b137-4043-96de-8928fa9f0f72.png)

**<font style="color:rgb(15, 17, 21);">梯度消失的本质，是深层网络在反向传播时，梯度连乘导致指数级衰减，使得模型的参数几乎无法更新，网络停止学习，</font>****<font style="color:rgb(51,51,51);">这就会造成网络是难以进行训练。</font>**

**<font style="color:rgb(51,51,51);">残差连接：它将网络某一层的输入，直接与经过该层变换后的输出进行逐元素相加，作为后续层的输入。</font>**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787888094369-9583e2fe-39cf-4b10-8698-12762d0ec7f7.png)

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787882396467-aaa20454-0b76-4058-8c7b-16adfb4d3180.png)

```python
#残差基本结构
import torch
import torch.nn.functional as F
from torch import nn

class ResBlock(nn.Module):
    def __init__(self,c):
        super().__init__()
        self.conv1 = torch.nn.Conv2d(c, c, 3, padding=1)
        self.conv2 = torch.nn.Conv2d(c, c, 3, padding=1)

    def forward(self, x):
        y = F.relu(self.conv1(x))
        y = self.conv2(y)
        return F.relu(y + x)

if __name__ == '__main__':
    x = torch.randn(1, 3, 32, 32)
    net = ResBlock(3)
    out = net(x)
    print(out)
    print(out.shape)
```

```python
#在网络中加入残差模块
class Net(torch.nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.conv1 = torch.nn.Conv2d(3, 64, 3, 1)
        self.resblock = ResBlock(64)
        self.conv2 = torch.nn.Conv2d(64, 128, 1, 1)
    def forward(self, x):
        out = self.conv1(x)
        x = self.resblock(out)
        y = self.conv2(x)
        return y
if __name__ == '__main__':
    x = torch.randn(1, 3, 32, 32)
    net = Net()
    out = net(x)
    print(out)
    print(out.shape)
```

**<font style="color:rgb(15, 17, 21);">残差连接通过引入恒等映射，将网络层的输出由 F(x) 变为 F(x)+</font>**_**<font style="color:rgb(15, 17, 21);">x</font>**_**<font style="color:rgb(15, 17, 21);">。在反向传播时，该操作的梯度为 ∂F/∂x+1，这个额外的‘+1’项为梯度提供了一条无损传播的捷径。即使中间层的变换梯度 ∂F/∂x 趋近于0，梯度依然能通过这条恒等路径直接传回浅层，从而有效切断连乘带来的衰减链条。</font>**

**<font style="color:rgb(15, 17, 21);">恒等映射（Identity Mapping）</font>**<font style="color:rgb(15, 17, 21);">，用最通俗的话说就是：</font>**<font style="color:rgb(15, 17, 21);">“输入是什么，输出就原封不动地是什么。”</font>**

<font style="color:rgb(15, 17, 21);">在数学上，它表示为 </font>**<font style="color:rgb(15, 17, 21);">f(x)=x</font>**<font style="color:rgb(15, 17, 21);">,也就是说，函数对输入的数据</font>**<font style="color:rgb(15, 17, 21);">不做任何变换</font>**<font style="color:rgb(15, 17, 21);">，直接将其作为结果传递出去。</font>

<font style="color:rgb(15, 17, 21);">在残差块中，核心公式是 </font>**<font style="color:rgb(15, 17, 21);">输出 = F(x)+x</font>**<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">这里的 </font>**<font style="color:rgb(15, 17, 21);">+</font>**_**<font style="color:rgb(15, 17, 21);">x</font>**_<font style="color:rgb(15, 17, 21);"> 就是恒等映射。它意味着：</font>**<font style="color:rgb(15, 17, 21);">不管中间的变换层 FF 把数据处理成什么样，我们都要把最原始的输入 </font>**_**<font style="color:rgb(15, 17, 21);">x</font>**_**<font style="color:rgb(15, 17, 21);"> 原封不动地加回去。</font>**

**<font style="color:rgb(15, 17, 21);">残差连接不仅从根本上缓解了梯度消失，还解决了深层网络的退化问题，使得训练成百上千层的超深网络成为可能。它是Transformer等现代大模型能够成功训练的核心架构设计之一，并且由于它让网络更容易学习恒等映射，也间接提升了模型的优化效率和收敛稳定性。</font>**

**<font style="color:rgb(15, 17, 21);"></font>**

:::info
### <font style="color:rgb(15, 17, 21);">一个生活类比</font>
<font style="color:rgb(15, 17, 21);">想象你在办公室里递送一份文件：</font>

+ **<font style="color:rgb(15, 17, 21);">普通网络</font>**<font style="color:rgb(15, 17, 21);">：每经过一个人，他都要把文件内容</font>**<font style="color:rgb(15, 17, 21);">重新手抄一遍</font>**<font style="color:rgb(15, 17, 21);">再递给下一个人。如果中间有一个人字迹潦草或抄错，后面的信息就失真了，传到老板那里可能完全变样（对应梯度消失）。</font>
+ **<font style="color:rgb(15, 17, 21);">残差网络（带恒等映射）</font>**<font style="color:rgb(15, 17, 21);">：每经过一个人，他除了抄写新内容F(x)，还必须把</font>**<font style="color:rgb(15, 17, 21);">原件</font>**<font style="color:rgb(15, 17, 21);">（x）和抄写本</font>**<font style="color:rgb(15, 17, 21);">装订在一起</font>**<font style="color:rgb(15, 17, 21);">递下去。这样一来，即使中间某个人的字迹完全看不清（F(x) 梯度为0），但</font>**<font style="color:rgb(15, 17, 21);">原件依然完好无损地传到了老板手里</font>**<font style="color:rgb(15, 17, 21);">（梯度通过恒等路径传回）。</font>

:::

### 2.2 梯度爆炸
**<font style="color:rgb(15, 17, 21);">梯度爆炸</font>**<font style="color:rgb(15, 17, 21);">：</font>**<font style="color:rgb(15, 17, 21);">在反向传播时，梯度不是像“梯度消失”那样归零，而是像滚雪球一样越滚越大，最终变成无穷大（NaN），导致网络权重被剧烈更新，彻底崩溃。</font>**

<font style="color:rgb(15, 17, 21);">假设一个50层的网络，链式法则展开后，梯度是50个数的连乘:</font>

+ **<font style="color:rgb(15, 17, 21);">梯度消失</font>**<font style="color:rgb(15, 17, 21);">：连乘的每个因子都 </font>**<font style="color:rgb(15, 17, 21);">< 1</font>**<font style="color:rgb(15, 17, 21);">（比如 0.5），导致结果 →0。</font>
+ **<font style="color:rgb(15, 17, 21);">梯度爆炸</font>**<font style="color:rgb(15, 17, 21);">：连乘的每个因子都 </font>**<font style="color:rgb(15, 17, 21);">> 1</font>**<font style="color:rgb(15, 17, 21);">（比如 2.0），导致结果 →∞。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1787897843250-95dc26a2-5ff1-4d17-bd9c-d80359aa2a7e.png)

**<font style="color:rgb(15, 17, 21);">梯度爆炸的本质是连乘效应：每层输出 </font>**_**<font style="color:rgb(15, 17, 21);">y</font>**_**<font style="color:rgb(15, 17, 21);">=</font>**_**<font style="color:rgb(15, 17, 21);">Wx</font>**_**<font style="color:rgb(15, 17, 21);"> 的数值范围在不断膨胀。要解决梯度爆炸，核心是控制每层输出的数值范围，不让它无限膨胀。</font>**

**BN(批归一化)，也就是 Batch Normalization，核心作用是：在神经网络训练时，把每一层中间结果的数值范围拉回到比较稳定的区间，****<font style="color:rgb(0, 0, 0);">数值不过大不过小,</font>****让后面的层更容易继续学习。(BN 做的事情：每过一层，先把这一批数据的队形整理一下，再交给下一层。)**

```python
import torch
from torch import nn

class LeNet5(nn.Module):
    def __init__(self, dropout_rate=0.5):
        super().__init__()
        #特征提取器 Conv → ReLU → Pool 反复出现
        #卷积提取局部模式，ReLU 引入非线性，池化降低空间分辨率并扩大有效视野。
        self.conv1 = nn.Sequential(
            nn.Conv2d(in_channels=3, 
                      out_channels=6, 
                      kernel_size=5, 
                      stride=1, 
                      padding=0,
                      bias=False),
            nn.BatchNorm2d(6),	# 在激活函数之前使用BN
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.conv2 = nn.Sequential(
            nn.Conv2d(in_channels=6, 
                      out_channels=16, 
                      kernel_size=5, 
                      stride=1, 
                      padding=0,
                      bias=False),
            nn.BatchNorm2d(16),	# 在激活函数之前使用BN
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2, padding=0)
        )
        
        self.flatten = nn.Flatten()
        
        self.fc1 = nn.Sequential(
            nn.Linear(400, 120,bias=False),
            nn.BatchNorm1d(120),	# 在激活函数之前使用BN
            nn.ReLU(),
            nn.Dropout(p=dropout_rate)
        )
        
        self.fc2 = nn.Sequential(
            nn.Linear(120, 84,bias=False),
            nn.BatchNorm1d(84),	# 在激活函数之前使用BN
            nn.ReLU(),
            nn.Dropout(p=dropout_rate)
        )
        
        self.fc3 = nn.Linear(84, 10)
        
    def forward(self, x):   
        out = self.conv1(x)
        out = self.conv2(out)
        out = self.flatten(out)
        out = self.fc1(out)
        out = self.fc2(out)
        
        logits = self.fc3(out)
  
        return logits

if __name__ == '__main__':
    net = LeNet5(dropout_rate=0.5)
    data = torch.randn(10, 3, 32, 32)
    output = net(data)
    print(output)
    print(output.shape)

```
