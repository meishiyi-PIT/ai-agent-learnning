# Python 基础补课清单

> 汇总 16 篇笔记里出现过的 Python 语法点，去重后按"出现频率/重要程度"排序。每篇笔记的「五、Python 随堂补基础」里都有针对该讲代码的具体示例，这里只做**索引 + 一句话讲清**，方便你先扫一遍知道自己卡在哪，再回对应笔记看例子。

## 一、地基语法（几乎每篇笔记都用到，必须先扫清）

| 语法点 | 一句话讲清 | 出现在 |
| :-- | :-- | :-- |
| f-string `f"{var}"` | 字符串里嵌变量最简写法；花括号本身要输出得写 `{{` `}}` 转义 | 02/04/06/07/12/13 |
| 列表推导式 `[x for x in lst if cond]` | "循环+过滤+收集"三合一，比写 for 循环+append 更 Python | 07/09/13/16 |
| try/except | 捕获异常不让程序崩，`except SpecificError` 比裸 `except:` 更安全 | 02/05/07/10/12 |
| 关键字参数（`func(a=1, b=2)`） | 按参数名传值，不按位置；**04/14 里两个真实 bug 都出在参数名传错** | 02/04/14/15 |
| 类型注解（`x: int`, `-> str`） | 只是提示，不强制类型检查，但能让 IDE/AI 更懂你的代码 | 01/02/04/08/09/15 |
| 切片 `lst[1:3]`、负索引 `lst[-1]` | 取子序列/倒数第几个，Java 没有直接对应写法 | 02/05/06/14 |
| 字典 `dict`/`json.dumps`/`json.loads` | Python dict ≈ Java HashMap，但字面量语法更轻量；与 JSON 天然对应 | 02/14 |

## 三、易被忽略的细节（容易踩坑，之前"没学通透"的重灾区）

| 语法点 | 一句话讲清 | 出现在 |
| :-- | :-- | :-- |
| `exec(code, globals, locals)` 双命名空间坑 | 传两个独立命名空间时，函数/推导式内部访问不到"顶层"变量（NameError），只传一个 globals 才对 | 05 |
| `dict` 浅拷贝 vs 深拷贝 | `dict.copy()` 只copy一层，嵌套的list/dict还是共享引用 | 05 |
| `zip(strict=True)` | Python 3.10+，两个序列长度不一致时直接报错而不是静默截断，写数据处理代码时更安全 | 16 |
| `or` 短路取默认值（`x = a or default`） | `a` 为假值（None/0/""）时才取 default，但要注意 `0`/`""` 这类"合法但假"的值会被误伤 | 16 |
| 三引号字符串 / 相邻字符串自动拼接 | `"a" "b"` 会自动拼成 `"ab"`，常见于把长 prompt 拆多行写 | 05/14 |

## 四、Java → Python 高频坑对照（你之前踩过的具体坑）

结合你实际写代码时反馈过的问题，这几条值得单独强化：

| Java 习惯 | Python 里为什么不一样 | 关联语法点 |
| :-- | :-- | :-- |
| 空构造 + setter 逐个赋值 | Python/Pydantic 更常见"构造时一次性传全部字段"（关键字参数），setter 模式在 Python 里少见，直接改属性或用 `@property` | 见上「关键字参数」「Pydantic BaseModel」 |
| 用元组/列表模拟字典查找 | Python 的 `dict` 本身就是一等公民、字面量极轻量（`{"a": 1}`），没必要绕远路用元组模拟键值对 | 见上「字典 dict」 |
| 方法忘记 return（Java 里 void 方法很常见） | Python 函数没写 `return` 默认返回 `None`，如果下游代码指望拿到值，会拿到 `None` 而不报错——**这是最隐蔽的 bug 来源之一**，因为 Python 不会像强类型语言那样在编译期报错 | 全篇通用，写完函数习惯性检查有没有该 return 的地方漏了 |
| for 循环手动 append 收集结果 | 列表推导式 `[f(x) for x in lst]` 是更地道的写法，比"新建空list+for+append"更短也更快 | 见上「列表推导式」 |
| 用局部变量名覆盖了内置函数/关键字（如 `list = [1,2,3]`、`id = 1`、`type = "x"`） | Python 的内置名（`list`/`dict`/`id`/`type`/`str` 等）只是普通全局变量，可以被你的局部变量**悄悄覆盖**，覆盖后本文件里再想用原本的 `list()` 函数就会报错——起名字避开这些内置名 | 通用注意事项 |
| 枚举值直接写裸字符串比较（`if role == "admin"`） | Java 有 `enum` 类型防止手误拼错；Python 对应用 `Literal["admin","user"]` 类型注解或真正的 `enum.Enum`，比裸字符串更能让 IDE/类型检查器帮你抓拼写错误——13 号笔记里 `Literal` 就是这个作用 | 见上「Pydantic + Literal」 |
