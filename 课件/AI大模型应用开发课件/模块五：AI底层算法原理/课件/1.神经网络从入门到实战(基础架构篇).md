深度学习是机器学习的一个分支，它是一种利用多层神经网络，从原始数据中自动学习特征，并完成预测或决策。

| 机器学习 | 深度学习 |
| --- | --- |
| <font style="color:rgb(13, 13, 13);">人工设计特征，模型学习规律</font> | <font style="color:rgb(13, 13, 13);">模型自动学习特征和规律</font> |

+ **<font style="color:rgb(13, 13, 13);">原始数据：</font>**<font style="color:rgb(13, 13, 13);"> 直接输入未经处理的底层信息（如 图像、文字、语音）。</font>

### 1.1 传统编程 vs 深度学习
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784859923929-aea78b03-935c-4a9c-b0fd-21d300bdbe58.png)
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103634595-d225c9e1-2827-45da-bfb2-fe569693fd16.png)
| 传统编程 | 深度学习 |
| --- | --- |
| 工程师手动编写规则 | 计算机从样本数据中寻找规则 |
| "如果耳朵是三角形，就有可能是猫" | 输入大量猫/非猫的图片 |
| "如果脸上有胡须，也许是猫" | 计算机自动总结特征 |
| 规则固定，难以覆盖所有情况 | 数据越多，识别越准 |


**深度学习换了一种思路**：不给规则，给数据和答案，让计算机自已从样本数据中寻找规律。

### 1.2 两大学习范式
根据训练数据带不带"标准答案"：

#### 1.2.1监督学习
好比有老师拿着答案陪你刷题：给你题目（输入）和标准答案（标签），你在反复练习中自己悟出规律。

+ **输入（题目）**：老师发下一套试卷。
+ **标准答案（标签）**：卷子背后印着**标准解题步骤和最终得分点**。
+ **学习过程**：同学们不仅自已做试题，做过多试题还对答案，还自己总结套路：
+ **考试（预测）**：期中考试，老师出了一道**从未见过的新题**（但考点一样）。小明沉着冷静，先判断题型属于“导数综合”，然后套用总结的步骤，顺利拿到了大部分步骤分。
+ **核心**：有明确的**标准答案**（真题解析），学习目标就是让解题思路无限逼近标准答案，最终在新题上也能拿分。

#### 1.2.2无监督学习
没有标准答案，靠自己去发现数据里的"团伙"——最常见的就是**聚类**，把相似的样本归到一起。

好比有老师突然“摆烂”了。他说：“今天不讲题，你们把自己高三以来所有试卷、练习册、作业本上的**错题**全部摊在桌上，自己整理。”

+ **输入（无标签数据）**：每个学生面前一堆错题——有三角函数算错的、有立体几何看错图的、有概率题审题漏条件的、有导数题不会分类讨论的……
+ **没有标准答案**：老师没说“你要把错题分成几类”或者“哪类最重要”。
+ **自发发现（聚类）**：整理了一下午后，每个学生都发现了自己的“死穴”：
    - **小红**发现：**“原来我80%的错题都是计算粗心，不是不会做”**（粗心类簇）
    - **小刚**发现：**“我的错题集中在解析几何，特别是联立方程算弦长那一步”**（知识盲区类簇）
    - **小丽**发现：**“我所有压轴题都只写了第一问，第二问根本读不懂题意”**（能力瓶颈类簇）

**核心**：没有**标签**（老师没给分类标准），学生（算法）自己根据错题之间的相似性（错误类型、知识点、难度）把错题**自动聚成几个团伙**，从而认清自己的薄弱环节。



### 1.3 分类 vs 回归
深度学习最基础的两类任务，选模型之前一定要搞清楚：

| 维度 | 分类 | 回归 |
| --- | --- | --- |
| 输出 | 离散的类别标签 | 连续的数值 |
| 举例 | 判断评论是好评还是差评 | 预测明天的气温 |

**容易搞混的场景**：目标检测里的预测框坐标 `(x1, y1, x2, y2)`——四个值都是连续数值，所以是回归问题，不是分类。

**同一个问题可以两边看**：

+ 电影票房 → 预测具体金额是回归；分成"扑街 / 回本 / 爆款"就是分类
+ 用户评分 → 预测具体 4.3 分是回归；分"好评 / 中评 / 差评"是分类

### 1.4 深度学习：当网络变深之后
传统机器学习得靠人手工设计特征——比如做车辆识别，你得自己琢磨提取轮廓、面积、长宽比这些特征。深度学习的做法是**端到端**——把图片和标签一起丢给网络，它从像素到语义一层层自己学。
![](https://cdn.nlark.com/yuque/__mermaid_v3/0e8b2188607418beeb7fbe2ce7bf24f7.svg)

**特征层级**是深度学习最精妙的地方：
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103699797-99a87de7-ff72-4cb3-88cf-d04a3fe93687.png)

+ **底层特征**：像素、边缘、颜色块——类似画画时的点和线，最原始的元素
+ **中层特征**：由边缘组合出的局部形状——眼睛的轮廓、嘴巴的弧线
+ **高层特征**：完整的人脸、物体——具有语义含义的整体概念

## 二、神经网络：逐层拆解
### 2.1 感知机(人工<font style="color:rgb(15, 17, 21);">神经元</font>)——一切的源头
#### 2.1.1从直觉出发：信贷员的决策
假设你是银行信贷员，要判断一个申请人是否值得放贷。你可能会看三个信息：

| 特征 | 直觉 |
| --- | --- |
| 年收入 | 越高越可能放贷 |
| 负债率 | 越高越危险 |
| 工作年限 | 越久越稳定 |


人类决策常常不是只看一个因素，而是综合打分。信贷员心里可能有这样的规则：

![image-20260811172750862](C:\Users\HUAWEI\Desktop\assets\image-20260811172750862.png)

然后和一个门槛比较——高于门槛就放贷，低于门槛就拒绝。这个**加权打分 + 阈值判断**的过程，就是感知机的核心思想！
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103762605-1f3ba10f-c02f-4458-9fd7-80a13532c5eb.png)

感知机就是把这个"加权判断"过程**数学化、自动化**。它接收多个输入（特征），每个输入乘以一个权重（重要程度），加起来后与一个阈值比较，超过阈值就输出 1（放贷），否则输出 0（拒绝）。关键在于：**权重不是人定的，而是感知机从数据中自动学出来的**。

这就是“机器学习”的早期雏形：机器不是只执行人写好的规则，而是根据样本不断修正规则。

#### 2.1.2生物神经元与人工神经元
感知机的设计灵感来自**生物神经元**。人脑有约 860 亿个神经元，每个神经元由**树突**（接收信号）、**细胞体**（处理信号）、**轴突**（输出信号）三部分组成。神经元之间通过**突触**连接，信号从一个神经元的轴突传到下一个神经元的树突。神奇的是，突触连接有**强弱**之分——连接强的信号影响大，连接弱的信号影响小。

感知机是对生物神经元一个极度简化的数学模型。
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103795134-207a2999-e506-4f9f-ba70-347f9c8728ea.png)
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103826280-ee216301-e13e-4999-b666-0a8655ee933b.png)



#### 2.1.3感知机的五个核心要素
一个感知机由五部分组成：

| 要素 | 符号 | 含义 |
| --- | --- | --- |
| 输入 | x1, x2, ..., xn | 样本数据 |
| 权重 | w1, w2, ..., wn | 每个样本数据的重要程度（权重表示数据对决策的影响方向和影响强度） |
| 偏置 | b | 决策的基础倾向 |
| 求和 | z | 综合得分 |
| 激活函数 | f(z) | 把得分变成分类结果 |


**权重 w₁, w₂, ..., wₙ** 是每个输入的"重要程度"，也是感知机要学习的核心参数。权重越大，说明该输入对决策的影响越大；权重为负，说明该输入越大越倾向于输出 0。

**偏置 b**（bias）是一个特殊的参数，它不与任何输入相乘，相当于一个"基础倾向"。偏置的作用是**调整决策阈值**：如果 b 很大，即使所有输入都为 0，感知机也可能输出 1；如果 b 很负，则需要输入足够大才能输出 1。在早期的感知机文献中，偏置常被写成 -θ（θ 是阈值），两者本质相同，只是符号约定不同。偏置就像信贷员的"风险偏好"。b 大 = 激进，容易放贷；b 小 = 保守，倾向拒绝。它让决策边界不必经过原点，而是可以平移到任意位置，增强了模型的表达能力。

#### 2.1.4感知机的数学模型
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784538714584-45e3833f-02f6-4a66-b652-88d7792735aa.png)


![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103859517-9e857fe3-ba68-4633-82f4-4228919b0a50.png)

**求和 z = Σwᵢxᵢ + b** 把所有加权输入累加起来，得到一个标量值。这个值反映了"综合得分"。最后**激活函数 f(z)** 把这个得分转换成最终输出。感知机最经典的激活函数是**符号函数（sign function）**：z > 0 时输出 1，z < 0 时输出 0。这个"非黑即白"的决策方式，正是感知机做二分类的基础。

把上面这套机制翻译成数学语言，就一句话：**把所有输入乘上各自的重要性（权重），加在一起，再决定输出多少。**

**<font style="color:rgb(15, 17, 21);">第一步</font>**<font style="color:rgb(15, 17, 21);">：把输入 </font><font style="color:rgb(15, 17, 21);">x</font><font style="color:rgb(15, 17, 21);">乘以权重 </font><font style="color:rgb(15, 17, 21);">w</font><font style="color:rgb(15, 17, 21);">，加上偏置 </font><font style="color:rgb(15, 17, 21);">b</font>_<font style="color:rgb(15, 17, 21);">  </font>_

![image-20260811173206633](C:\Users\HUAWEI\Desktop\assets\image-20260811173206633.png)

**<font style="color:rgb(15, 17, 21);">第二步</font>**<font style="color:rgb(15, 17, 21);">：将 </font><font style="color:rgb(15, 17, 21);">z</font><font style="color:rgb(15, 17, 21);">送入一个</font>**<font style="color:rgb(15, 17, 21);">非线性函数</font>**<font style="color:rgb(15, 17, 21);">（即激活函数）</font>。感知机最经典的激活函数是**符号函数（sign function）**：

![image-20260811173234327](C:\Users\HUAWEI\Desktop\assets\image-20260811173234327.png)
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784103895719-6574fa6f-6422-40b7-878d-ca70357a1951.png)

用向量形式写更简洁：**z = wᵀx + b，y = sign(z)**。其中 w 是权重向量，x 是输入向量，wᵀx 是它们的内积。这个简洁的公式就是感知机的全部数学模型。虽然简单，但它已经具备了一个"分类器"的基本能力——通过调整 w 和 b，可以在输入空间中画一条线，把不同类别的样本分开。

苹果通常甜度高、偏红；橘子甜度中等、偏橙。

假设模型已经学到：w1=0.6,w2=0.8,b=-7

于是：

感知机决策的三个特点：

• 权重 = 特征重要性：权重越大，表示这个特征越关键，该特征对决策影响越大

#### 2.2.2 Sigmoid
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784184227023-21d5f880-d043-4538-a9b7-382356881bd3.png)

Sigmoid 做的事非常简单：**不管输入多大或多小，一律压扁到 (0, 1) 之间**。输入是一个巨大的正数 → 输出逼近 1；输入是一个巨大的负数 → 输出逼近 0；输入是 0 → 输出刚好 0.5。

它的曲线是一条优美的 S 形——两端平缓，中间陡峭。

**为什么早期很受欢迎？** 两个原因：一是输出天然在 0~1 之间，可以直接当概率用；二是曲线的形状和生物神经元"抑制-兴奋"的开关模式有点神似。

**为什么现在几乎没人用了？** 因为它有一个致命缺陷——**梯度消失**。你看 S 曲线的两端非常平，意味着在这些区域，输入变一点，输出几乎不变。反向传播时梯度一层层乘回去，乘到这些接近零的数，前面层的参数就再也更新不动了。深层网络直接废掉。

---

#### 2.2.3 Tanh
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784184650446-287fb487-b7ea-4ad5-bbfa-2820b804062e.png)

Tanh 跟 Sigmoid 长得太像了——都是 S 形曲线。唯一区别是 Tanh 的输出范围是 **(-1, 1)**，比 Sigmoid 的 (0, 1) 多了一个优点：输出**零均值**。

零均值为什么重要？如果上一层神经元输出的全是正数（比如 Sigmoid 的 0~1），下一层算梯度时所有权重的更新方向会被"绑在一起"——要么一起增、要么一起减。参数更新像醉汉走路，歪歪扭扭效率低。Tanh 输出有正有负，更新方向更自由，收敛更快。

但 Tanh 的致命伤跟 Sigmoid 一模一样——两端导数趋近于零，**梯度消失照旧**。所以在前馈网络的隐藏层里，它也被 ReLU 取代了。

> Tanh 现在主要活在 RNN / LSTM 这类循环网络里。
>

#### 2.2.4 ReLU
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784185001838-4d562c63-598a-44ca-8163-0924b165ad64.png)

ReLU 全名叫"线性整流单元"：**负数全变零，正数照常过。**

比 Sigmoid 少了指数运算、少了曲线平滑——就是一条折线。

**为什么它能统治深度学习十几年？** 三个原因：

1. **根治梯度消失（至少在正半轴）**：只要输入是正数，梯度永远是 1。反向传播时 1 乘 1 乘 1……乘多少层也不衰减。这是它干掉 Sigmoid 的核心武器。
2. **计算快到几乎免费**：判断正负 + 赋值，比指数运算快几十倍。当你有上百万个神经元、训练几万轮时，这个差距意味着几分钟和几小时的区别。
3. **天然产生稀疏性**：大约一半的输入是负数 → 输出 0 → 这些神经元暂时"休眠"(模拟人脑的工作方式，人脑中能被同时激活的神经元，基本只占整体的1%到4%左右)。这不是 bug，而是意外收获——网络被迫用更少的活跃神经元表达信息，反而更不容易死记硬背。

**但它有个著名的大坑——Dead ReLU**：如果某个神经元不幸地对所有输入都输出 0，那反向传播时它的梯度也永远是 0，参数再也更新不了——这个神经元就彻底"死"了。

**补救思路很简单**——给负数留一口气，别赶尽杀绝。于是有了 LeakyReLU（负数不归零，而是乘以一个很小的斜率比如 0.01）和 PReLU（这个斜率不让人类设定，而是让网络在训练中自己学出来）。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784188730204-16bba965-1d2b-4244-b6bf-190d38caeaa0.png)

> 直接用 ReLU 或其变体，90% 的情况稳得很。
>

### 2.3 为什么"深"才有意义
<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785467612642-74db5322-c958-43ee-9822-5432b13738f6.png)

<font style="color:rgb(15, 17, 21);">在数学上，函数的定义是：</font>**<font style="color:rgb(15, 17, 21);">给定一个输入，按照某种确定的规则，产生唯一对应的输出。</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">神经网络完全符合这个定义。</font>

+ **<font style="color:rgb(15, 17, 21);">输入</font>**<font style="color:rgb(15, 17, 21);">：一张图片的像素值（比如28x28=784个数字）。</font>
+ **<font style="color:rgb(15, 17, 21);">输出</font>**<font style="color:rgb(15, 17, 21);">：分类标签（比如“猫”的概率0.98），或者预测的房价数值。</font>
+ **<font style="color:rgb(15, 17, 21);">映射规则</font>**<font style="color:rgb(15, 17, 21);">：神经网络的权重和偏置（即那些成千上万的参数）。</font>

**<font style="color:rgb(15, 17, 21);">神经网络的“表达能力”</font>**<font style="color:rgb(15, 17, 21);">，就是指</font>**<font style="color:rgb(15, 17, 21);">这个网络能“画”出多么复杂的数据分界线，或者能“模拟”多么扭曲复杂的数学函数。</font>**

单层网络相当于只有一个"加工车间"。加上激活函数后，单个神经元可以输出非线性结果，但整体表达能力依然有限。

于是你多堆几层——这就是多层全连接网络：

**"全连接"是什么意思？** 就是每一层的**每一个**节点，都和下一层的**每一个**节点连着——信息全量传递，不跳过任何一个。
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784105013122-da621c20-fa46-486f-80f4-32605ce0ceb5.png)



![](https://cdn.nlark.com/yuque/__mermaid_v3/b807868d948d8600e51a756fca4e0c35.svg)

**不同层学不同抽象级别的特征**：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784528683898-755a0fde-db74-49bd-b689-6a55c8614081.png)

```plain
输入层：  原始像素值（一堆代表颜色的数字）
   ↓
隐藏层1： 边缘、颜色块（低级特征：点在哪里、线往哪走、色块边界在哪）
   ↓
隐藏层2： 形状、纹理（中级特征：这里有个圆、那里有尖角、条纹方向）
   ↓
隐藏层3： 眼睛轮廓、鼻子形状（高级特征：具备了语义的局部概念）
   ↓
输出层：  "这是一只猫"
```

**正是这种逐层抽象的机制，让神经网络具备了自动学习特征的能力。**

**参数量的爆炸**是深度网络一个很直观的特点。举个例子：3 个输入 → 4 个隐藏节点 → 2 个隐藏节点 → 3 个输出，总参数量 = 3×4 + 4×2 + 2×3 = 26 个。

![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784105105687-c174924e-8b2f-4b0c-834d-5613ff57dc6e.png)

现实中的大模型——比如 DeepSeek 的旗舰版本——参数量动辄数千亿，每一层都有成千上万个神经元。这就是"大"模型的由来。

> 研究表明：参数总量相同时，**更深的网络通常比更宽的网络表现更好**。这也是"深度学习"这名字的由来——重点在"深"。

### 2.5 前向传播——数据怎么流
前向传播就是数据从输入层开始，一层层计算、一层层传递，最终输出预测值结果的过程，就是一条计算流水线。

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/gif/21571931/1784258159052-c5fccb48-bd5a-489f-b47a-f6d6b204d840.gif)

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784256197012-31c12a5e-4c06-461d-b08e-a076f78de5e9.png)

就像工厂的流水线：原材料从一端放入，经过一道道工序加工，产出成品（前向传播）。

<font style="color:rgb(15, 17, 21);">前向传播是神经网络推理的核心过程，它像一条单向的数据流水线：输入数据从输入层进入，逐层乘以权重并加上偏置，再经过每层特定的激活函数（如ReLU或Sigmoid）进行非线性变换，这样层层传递、抽象，从而提取出越来越抽象的特征。直到抵达输出层，最终生成预测结果。整个过程中，信息严格从前往后流动，不涉及任何参数调整。</font>

### 2.6 用矩阵重新理解一切
前面用逐元素的方式描述网络：每个神经元接收上一层的全部输出，各自乘上权重、求和、过激活函数。如果一个一个列公式，两个神经元要写两行，一百个神经元能把纸写满。

**用矩阵运算，一个公式搞定整层神经网络**：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1785830134903-e60c2bbe-870f-4a30-96ac-e202a950b4ae.png)

+ 把前一层的所有输出打包成一个**列向量**
+ 把该层的所有权重排成一个**矩阵**（行数 = 本层神经元数，列数 = 前层神经元数）
+ 矩阵乘法自动完成"每个神经元对每个输入加权求和"的操作
+ 最后统一过激活函数

这不只是写法简洁——**关键在硬件**。GPU 有成千上万个计算核心，专门为矩阵乘法做了极致优化。一个 1000×1000 的矩阵乘法，在 GPU 上可以同时计算所有位置，耗时和算一个位置差不多。而 CPU 只能一个一个循环，慢了不止一个数量级。

> 这就是为什么深度学习离不开 GPU。国内外的深度学习框架底层，都是把前向和反向传播转化成矩阵运算，再交给 GPU 的专用数学库去跑。理解"**一层网络 = 矩阵乘法 + 激活函数**"这句话，你就抓住了现代深度学习框架的核心抽象。
>

:::info
换轴 = 重新排列轴编号的顺序

换轴不改变数据本身（数字0还是0，1还是1），它改变的是我们访问这些数据的索引顺序

换轴（transpose 或 permute）时，本质上就是改变这三个数字(2,3,4)的顺序

原始轴的顺序是：[0, 1, 2] 对应形状 (2, 3, 4) 

第0层（d=0）:

[[ 0,  1,  2,  3],    <- 第0行

 [ 4,  5,  6,  7],    <- 第1行

 [ 8,  9, 10, 11]]    <- 第2行



第1层（d=1）:

[[12, 13, 14, 15],    <- 第0行

 [16, 17, 18, 19],    <- 第1行

 [20, 21, 22, 23]]    <- 第2行



如果执行换轴操作 tensor.permute(2, 0, 1),轴的顺序从 [0, 1, 2] 变成了 [2, 0, 1],形状变成(4,2,3)。

把原来的轴2 放到新张量的轴0位置，原来的轴0 放到新张量的轴1位置，原来的轴1 放到新张量的轴2位置。

这意味着我们要把原来的维度重新排列：

新的第0维→取原来的第2维（列/宽度）

新的第1维→取原来的第0维（层/深度）

新的第2维→取原来的第1维（行/高度）

第0层 (d=0): 取所有原矩阵的第0列

  [[ 0,  4,  8],   

   [12, 16, 20]]   



第1层 (d=1): 取所有原矩阵的第1列

  [[ 1,  5,  9],

   [13, 17, 21]]



第2层 (d=2): 取所有原矩阵的第2列

  [[ 2,  6, 10],

   [14, 18, 22]]



第3层 (d=3): 取所有原矩阵的第3列

  [[ 3,  7, 11],

   [15, 19, 23]]

:::

from torch import nn
import torch

class FullyConnectedNet(nn.Module):
    def __init__(self):
        super().__init__()
        # nn.Sequential是一个容器 会按顺序执行每一层，形成一个顺序执行的模块。
        # 数据从一端进入，按顺序经过里面的每一层，最后从另一端输出。
        self.layer = nn.Sequential(
            #展平，把n维数组压平成一维数组，默认展平：保留 batch 维度，其余合并
            nn.Flatten(),             # [batch, 1, 28, 28] -> [batch, 784]
            nn.Linear(28 * 28, 512),  # 784 个像素点映射到 512 个隐藏特征
            nn.ReLU(),                # 增加非线性表达能力
            nn.Linear(512, 256),      # 继续提取更紧凑的隐藏特征
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10),       # 模型输出的原始分数(分数越高，说明模型当前越偏向哪个候选项)
        )

    def forward(self, x):
        # forward 定义“数据如何从输入流到输出”。
        # 输入 x 是一批图片，输出是每张图片对应 10 个数字类别的 logits。
        return self.layer(x)


if __name__ == '__main__':
    data = torch.randn(1,1,28,28)
    net = FullyConnectedNet()
    output = net(data)
    print(output)

### 2.8 输出函数
<font style="color:rgb(34, 34, 34);">神经网络最后加入的输出函数，最核心的作用就是</font>**<font style="color:rgb(34, 34, 34);">决定模型最终输出的数值范围和物理意义</font>**<font style="color:rgb(34, 34, 34);">。如果没有它，网络最后输出的只是一些毫无约束的原始分数，</font>比如 数值越大，只表示模型当前越倾向于对应类别。而加上输出函数之后，把_原始分数_转换为概率.

**<font style="color:rgb(34, 34, 34);">把模型输出变成概率的好处：</font>**

1. **<font style="color:rgb(15, 17, 21);">统一尺度，让结果直观可比。</font>**

<font style="color:rgb(34, 34, 34);">       </font><font style="color:rgb(15, 17, 21);">概率将输出严格限制在 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[0, 1]</font>`<font style="color:rgb(15, 17, 21);"> 区间，且所有类别的概率之和为 1。这样一来，无论模型之前算出的是天文数字还是负无穷，最终都体现在同一把“尺子”上——你可以直接说“猫的概率 80%，狗的概率 15%”，清晰、可解释。</font>

2. **<font style="color:rgb(15, 17, 21);">提供“置信度”，区分“确信”与“猜测”</font>**

**<font style="color:rgb(15, 17, 21);">      </font>****置信度:****<font style="color:rgb(15, 17, 21);">模型对自己给出的答案“有多确定”的量化表达，通常用百分比（0~100%）来表示, 模型为最终选中的那个类别所分配的概率值.</font>**

+ <font style="color:rgb(15, 17, 21);">情况A：模型输出“是肿瘤”，</font>**<font style="color:rgb(15, 17, 21);">概率 99.9%</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">→ 医生可以果断安排手术。</font>
+ <font style="color:rgb(15, 17, 21);">情况B：模型输出“是肿瘤”，但</font>**<font style="color:rgb(15, 17, 21);">概率只有 51%</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">→ 医生会要求复查，而不是盲目动刀。</font>

<font style="color:rgb(15, 17, 21);">概率值让我们能感知模型的“信心水平”，这是原始分数完全做不到的。</font>

3. **<font style="color:rgb(15, 17, 21);"> 支持灵活的策略阈值</font>**<font style="color:rgb(34, 34, 34);">。</font>

<font style="color:rgb(15, 17, 21);">有了概率，我们就可以根据不同置信度设置分级处理逻辑。例如垃圾邮件拦截系统：</font>

+ <font style="color:rgb(15, 17, 21);">概率</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">> 90%</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">→ 直接拦截</font>
+ <font style="color:rgb(15, 17, 21);">概率</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">70% ~ 90%</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">→ 放入“可疑邮件”文件夹，人工复核</font>
+ <font style="color:rgb(15, 17, 21);">概率 </font>**<font style="color:rgb(15, 17, 21);">< 70%</font>**<font style="color:rgb(15, 17, 21);"> → 直接放行</font>



**<font style="color:rgb(34, 34, 34);">分类任务（比如识别图片是猫、狗还是鸟）：</font>**<font style="color:rgb(34, 34, 34);"> 我们通常使用 </font>**<font style="color:rgb(34, 34, 34);">Softmax 函数</font>**<font style="color:rgb(34, 34, 34);">。它能把多个输出值转换成总和为 1 的概率分布，让你清楚地看到模型认为这张图有 80% 的概率是猫，15% 是狗，5% 是鸟。</font>

<font style="color:rgb(63, 63, 63);">Softmax 完成了两件事：</font>

+ <font style="color:rgb(63, 63, 63);">1. 把每个结果限制在 0 到 1 之间；</font>
+ <font style="color:rgb(63, 63, 63);">2. 让所有类别的概率之和等于 1。</font>

**Softmax公式很自然的就解决了从得分映射到概率的问题。**

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/21571931/1784274315402-44ae2b46-6f12-43ff-b7f1-ef69f0607751.png)

<font style="color:rgba(0, 0, 0, 0.9);">公式中，每个 z 就对应了多个分类的得分值。SoftMax对得分值进行了如下处理：</font>

+ <font style="color:rgba(0, 0, 0, 0.9);">以e为底数进行了指数运算，算出每个分类的 eZi，作为公式的分子</font>
+ <font style="color:rgba(0, 0, 0, 0.9);">分母为各分类得分指数运算的加和。</font>
+ <font style="color:rgba(0, 0, 0, 0.9);">根据公式很自然可以想到，各个分类的SoftMax值加在一起是1，也就是100%。所以，每个分类的SoftMax的值，就是将得分转化为了概率，所有分类的概率加在一起是100%。 </font>

```python
#Softmax(x_i) = exp(x_i) / Σ exp(x_j)
x = torch.tensor([2,1,0.1]) # 三分类的 logits
y = torch.softmax(x, dim=0)
# ===== 手动展开计算过程 =====
# 1. 输入向量: [2.0, 1.0, 0.1]
# 2. 对每个元素取指数:
#    exp(2.0) = e^2   ≈ 7.389
#    exp(1.0) = e^1   ≈ 2.718
#    exp(0.1) = e^0.1 ≈ 1.105
# 3. 求和:
#    7.389 + 2.718 + 1.105 = 11.212
# 4. 每个元素除以总和:
#    softmax(2.0) = 7.389 / 11.212 ≈ 0.659
#    softmax(1.0) = 2.718 / 11.212 ≈ 0.242
#    softmax(0.1) = 1.105 / 11.212 ≈ 0.099
# 5. 验证结果和为 1:
#    0.659 + 0.242 + 0.099 ≈ 1.0
print("Softmax 输入:", x)
print("Softmax 输出:", y)
print("和为:", y.sum())
#Softmax 输入: tensor([2.0000, 1.0000, 0.1000])
#Softmax 输出: tensor([0.6590, 0.2424, 0.0986])
#和为: tensor(1.0000)
```

from torch import nn
import torch

class FullyConnectedNet(nn.Module):
    def __init__(self):
        super().__init__()
        # nn.Sequential 会按顺序执行每一层。
        self.layer = nn.Sequential(
            nn.Flatten(),             # [batch, 1, 28, 28] -> [batch, 784]
            nn.Linear(28 * 28, 512),  # 784 个像素点映射到 512 个隐藏特征
            nn.ReLU(),                # 增加非线性表达能力
            nn.Linear(512, 256),      # 继续提取更紧凑的隐藏特征
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 10),       # 输出 10 个数字类别的分数
            
            #输出函数
            nn.Softmax(dim=1)  # NV结构，激活V
        )

    def forward(self, x):
        # forward 定义“数据如何从输入流到输出”。
        # 输入 x 是一批图片，输出是每张图片对应 10 个数字类别的 logits。
        return self.layer(x)


if __name__ == '__main__':
    data = torch.randn(1,1,28,28)
    net = FullyConnectedNet()
    output = net(data)
    print(output)
